# План розробки броузингу мережевих джерел (WebDAV, FTP, HTTP, SMB)

Цей файл описує план реалізації броузингу та файлових операцій для всіх типів мережевих джерел (WebDAV, FTP, HTTP, SMB) у файловому менеджері Sphaira.

## План дій

1. **Devoptab реалізація для Curl пристроїв** `[Виконано]`:
   - Реалізувати віртуальні функції файлової системи (`devoptab_open`, `devoptab_diropen` тощо) у `MountCurlDevice`.
   - Забезпечити підтримку читання, запису, лістингу та базових операцій (видалення, створення папок).

2. **Навігація через System Root** `[Виконано]`:
   - Додати тип `FsType::Root`.
   - Змінити логіку кнопки B ("назад") у `filebrowser.cpp`: при виході з корню microSD або мережевого пристрою переходити у віртуальний `System Root`.
   - У `System Root` відображати:
     - microSD.
     - Системні розділи (NAND, SD Image) за умови увімкненого God Mode (DOS).
     - Додані мережеві джерела з їх поточним статусом підключення.

3. **Обробка підключень та статусів** `[Виконано]`:
   - Додати красиве відображення статусів підключення (галочки, хрестики, сірі кола) у списку пристроїв.
   - Забезпечити автоматичне монтування при виборі розмонтованого пристрою.

4. **Розблокування перевірок** `[Виконано]`:
   - Зняти обмеження протоколів у налаштуваннях та меню вибору джерел, замінивши повідомлення про непідтримуваний протокол на повноцінне підключення.
