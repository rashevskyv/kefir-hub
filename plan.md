# План реалізації: Виправлення відображення файлів на MTP-пристрої та авто-демонтування (v0.13.355)

Цей реліз вирішує проблеми з переглядом папок смартфона у `mtp0:` та фальшивими сповіщеннями при від'єднанні кабелю.

## Зроблені зміни

1. **MTP Data Phase (`ReceiveMtpData`)**:
   - Реалізовано зчитування багатьох пакетів у циклі для MTP Data container, якщо `hdr->length` перевищує обсяг першого буфера `transferred`. Це усуває залишки даних у USB-каналi та запобігає USB stall.

2. **Запит кореня MTP (`FetchDirectoryEntries`)**:
   - Першим кандидат-ParentHandle для кореневої папки опитується `0x00000000` (стандарт MTP для Android), а потім `0xFFFFFFFF`.

3. **Перевірка активного підключення (`ScanAndMountMtpDevices`)**:
   - Активна MTP-сесія перед вибором кешованого носія опитується командою `GetDeviceInfo (0x1001)`. У разі відключення пристрою або збою викликається `CloseMtpSessionLocked()`, що чистить змонтовані пристрої та скидає кеш.

4. **Безпечне читання UTF-16 імен**:
   - Виправлено непарні зсуви касту покажчика UTF-16, впроваджено побайтове конвертування для запобігання помилкам вирівнювання ARM64.

5. **Версіонування**:
   - Версію програми ітеровано до `0.13.355` у [CMakeLists.txt](file:///d:/git/dev/sphaira/sphaira/CMakeLists.txt#L3).
