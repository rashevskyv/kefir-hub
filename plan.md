# План реалізації: Виправлення розпізнавання префікса пристрою у devoptab для MTP (v0.13.356)

Цей реліз усуває ключову проблему, через яку вхід у `mtp0:` повертав порожній список ("Пусто").

## Зроблені зміни

1. **Очищення префікса пристрою (`ResolvePathToHandle`)**:
   - Системний виклик devoptab `opendir("mtp0:/")` передає в метод драйвера повний рядок шляху з префіксом точки монтування. Метод `ResolvePathToHandle` намагався знайти на пристрої папку з буквальним ім'ям `"mtp0:"`, що призводило до помилки `0` (not found) і повертало 0 записів.
   - Додано автоматичне очищення будь-якого префікса з двокрапкою `*:`, завдяки чому `"mtp0:/"` успішно розпізнається як корінь MTP-диска (`0xFFFFFFFF`), а підпапки (наприклад `"mtp0:/Download"`) коректно резолвляться в їхні ідентифікатори об'єктів handles.

2. **Версіонування**:
   - Версію програми ітеровано до `0.13.356` у [CMakeLists.txt](file:///d:/git/dev/sphaira/sphaira/CMakeLists.txt#L3).
