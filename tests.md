# Інструкція для тестування змін на реальній консолі (v0.13.198 — v0.13.229)

Цей файл містить перелік живих тестів, які необхідно виконати на реальній консолі Nintendo Switch для підтвердження коректності внесених змін у версіях з **v0.13.198** по поточну **v0.13.229**.

---

## 16. Рефакторинг налаштування мережевих джерел та контекстне меню (v0.13.229)

- [ ] **Тест: Швидке додавання джерела та перехід до налаштування**
  1. Перейдіть до `Tools -> Settings -> Sources` та оберіть `+ Add network location`.
  2. Оберіть протокол (наприклад, `Samba (SMB)`).
  3. Введіть назву (наприклад, `HomeNAS`).
  4. Перевірте, що джерело миттєво додається до списку без запиту інших реквізитів і відображається як `HomeNAS`.
  5. Перевірте, що при натисканні `A` на новоствореному джерелі відкривається меню редагування `Edit Source` зі списком полів: `Server IP / Hostname`, `Share Name`, `Username`, `Password`.
  6. Введіть валідні реквізити Samba (IP-адресу та ім'я спільної папки).

- [ ] **Тест: Миттєвий перехід у Файловий менеджер**
  1. Налаштуйте повністю будь-яке Samba джерело в меню (введіть IP-адресу та ім'я спільної папки).
  2. Поверніться до списку джерел у `Settings -> Sources`.
  3. Натисніть `A` на повністю налаштованому Samba джерелі.
  4. Переконайтеся, що програма автоматично відкриває Файловий менеджер та намагається підключитися/увійти в це Samba джерело.

- [ ] **Тест: Контекстне меню на PLUS (+)**
  1. У списку `Settings -> Sources` виділіть будь-яке джерело (наприклад, `HomeNAS`).
  2. Натисніть кнопку `+` (PLUS) на геймпаді. Перевірте, що внизу екрана зсув легенди показує кнопку `+ START Options`.
  3. Перевірте, що відкрився PopupList з опціями: `Enter/Connect`, `Edit`, `Rename`, `Properties`, `Delete`.
  4. Перевірте роботу кожної опції:
     - `Properties` має вивести детальну інформацію про джерело (Name, Protocol, URL, etc.).
     - `Rename` має успішно перейменувати джерело через swkbd клавіатуру.
     - `Delete` ("Delete this network location?") має видалити джерело після вікна підтвердження.

## 15. Миттєве оновлення списку перекладів у меню після завантаження (v0.13.228)

- [ ] **Тест: Оновлення списку мовних пакетів без перезаходу в меню**
  1. Видаліть файл `TRANSLATE_PACKAGE` та папку `TRANSLATE_PACKAGE_DIR` на SD-карті (якщо вони існують).
  2. Перейдіть до `Tools -> Settings -> Translate Interface`.
  3. Переконайтеся, що перший пункт називається `"Download language packs"`, а під ним немає списку конкретних мовних пакетів (оскільки файлу списку немає).
  4. Натисніть `A` на `"Download language packs"`.
  5. Зачекайте, поки завантаження та розпакування завершаться (вікно прогресу зникне).
  6. Перевірте, що **одразу ж на цьому самому екрані** назва першого пункту змінилася на `"Update language packs"`, а нижче з'явився повний список доступних мовних пакетів (наприклад, `Ukrainian`, `Spanish` тощо) для вибору. Не потрібно виходити з меню і заходити знову.

## 14. Виправлення помилки 0x1002 при встановленні перекладу інтерфейсу (v0.13.227)

- [ ] **Тест: Встановлення українського перекладу інтерфейсу**
  1. Перейдіть до `Tools -> Settings -> Translate Interface`.
  2. Оберіть `Ukrainian` та натисніть `A`.
  3. Оберіть будь-який сумісний варіант заміни (наприклад, `Russian for Europe region` або `English for Europe region`).
  4. Перевірте, що завантаження та розпакування проходять успішно, і **не виникає вікна помилки "Code: 0x1002 Module: 2 (Fs)"**.
  5. Перевірте, що консоль успішно перезавантажується після завершення встановлення.

- [ ] **Тест: Прокрутка списку без накладання на хедер**
  1. Перейдіть до `Tools -> Settings -> Translate Interface`.
  2. Прокрутіть список вниз так, щоб перші елементи (наприклад, `Indonesian` або `Kazakh`) зсунулися вгору за межі видимості.
  3. Перевірте, що елементи зникають (обрізаються) рівно по нижній межі розділювача хедера (координата `y = 132` / `120`) і не накладаються на текст заголовка `"Переклад інтерфейсу"`.
  4. Перевірте те саме в інших розділах налаштувань (`Software`, `DBI`, `Kefir Settings`, `Themes`).

## 13. Оновлення мовних пакетів, кругова навігація та фільтрація варіантів перекладу (v0.13.225)

- [ ] **Тест: Кругова навігація у підменю налаштувань**
  1. Перейдіть до `Tools -> Settings`.
  2. Зайдіть у будь-яке підменю з налаштувань, наприклад `Software`, `DBI`, `Kefir Settings`, `Themes` або `Translate Interface`.
  3. Перебуваючи на першому пункті меню, натисніть кнопку "Вгору" (D-Pad Up).
  4. Переконайтеся, що виділення перемістилося на останній пункт списку.
  5. Перебуваючи на останньому пункті меню, натисніть кнопку "Вниз" (D-Pad Down).
  6. Переконайтеся, що виділення перемістилося на перший пункт списку.

- [ ] **Тест: Динамічний текст мовних пакетів**
  1. Перейдіть до `Tools -> Settings -> Translate Interface`.
  2. Якщо мовні пакети ще не завантажені (видаліть файл `TRANSLATE_PACKAGE` на SD карті, якщо він був), переконайтеся, що перший пункт називається `"Download language packs"`, а підзаголовок — `"Download the UltraHand language package list."`.
  3. Натисніть `A` для завантаження. Перевірте, що повідомлення процесу завантаження відображає `"Downloading language packs..."`.
  4. Після завантаження перевірте, що назва першого пункту змінилася на `"Update language packs"`, а підзаголовок — на `"Update the UltraHand language package list."`.
  5. Запустіть оновлення і переконайтеся, що вікно прогресу показує `"Updating language packs..."`.

- [ ] **Тест: Фільтрація перекладів за мовою та регіоном**
  1. Перейдіть у `Tools -> Settings -> Translate Interface`.
  2. Переконайтеся, що для мов, які мають декілька регіональних варіацій (наприклад, англійська чи російська), показуються тільки сумісні варіанти відповідно до поточної мови та регіону вашої консолі.
  3. Змініть мову або регіон консолі в системних налаштуваннях консолі на несумісні (наприклад, на японську мову) і перейдіть у `Translate Interface` -> оберіть переклад, який не має сумісних варіантів для вашої мови/регіону.
  4. Переконайтеся, що з'являється попередження `OptionBox` із текстом `"To apply this translation, you must select one of the required variations in the console settings:"` та списком усіх доступних версій перекладу.

## 12. Виправлення крашу та покращення WebDAV інтеграції (v0.13.224)

- [ ] **Тест: Додавання джерела без протоколу у назві**
  1. Перейдіть до `Tools -> Settings -> Sources` та оберіть `Add network location`.
  2. Оберіть протокол `WebDAV`.
  3. Введіть назву джерела (наприклад, `Nextcloud`).
  4. Введіть хост джерела БЕЗ префікса протоколу (наприклад, `dev.customfw.xyz`).
  5. Переконайтеся, що після заповнення інших полів джерело успішно створюється, і при цьому **не виникає чорного екрана Atmosphere fatal error (0xFFE/Data Abort)**.

- [ ] **Тест: Відображення та підсвічування активної локації WebDAV Settings**
  1. Додайте джерело `WebDAV` у `Sources` (наприклад, `Nextcloud`).
  2. Перейдіть у `Tools -> Settings -> WebDAV`.
  3. Оберіть `Sync Location` та виберіть `Nextcloud`.
  4. Вийдіть у головне меню, а потім знову перейдіть у `Tools -> Settings -> WebDAV`.
  5. Переконайтеся, що навпроти `Sync Location` відображається назва джерела `Nextcloud` (воно коректно підсвічується і не злітає на `"None"`).

- [ ] **Тест: Захист від порожніх списків ігор та додатків**
  1. Перейдіть до меню `Games` та `Apps`.
  2. Переконайтеся, що списки завантажуються коректно.
  3. Якщо списки порожні, переконайтеся, що програма залишається стабільною і не крашиться.

## 11. Виправлення Use-After-Free крашу при додаванні джерел (v0.13.223)

- [ ] **Тест: Додавання джерела без вильоту Atmosphere**
  1. Перейдіть до `Tools -> Settings -> Sources` чи `File Browser -> Sources` та оберіть `Add network location`.
  2. Додайте будь-яке джерело (наприклад, WebDAV) з будь-якою назвою хоста (наприклад, `dev.customfw.xyz`).
  3. Переконайтеся, що після заповнення всіх полів та натискання OK програма показує повідомлення `"Location added successfully!"` та повертається на екран списку джерел.
  4. Переконайтеся, що програма залишається стабільною, а консоль **не крашиться у чорний екран Atmosphere fatal error**.

## 10. Єдине джерело істини для WebDAV сейвів (v0.13.222)

- [ ] **Тест: Вибір активного спільного джерела для сейвів**
  1. Перейдіть до `Tools -> Settings -> Sources` (або `File Browser -> Sources`) та додайте нове WebDAV джерело (наприклад, з назвою `"Nextcloud"`).
  2. Перейдіть до `Tools -> Settings -> WebDAV` (WebDAV Settings).
  3. Переконайтеся, що замість полів введення адреси сервера, імені користувача та пароля відображається пункт `"Sync Location"` зі значенням `"None"`.
  4. Натисніть на `"Sync Location"`, переконайтеся, що відкрився PopupList з опціями `"None"` та `"Nextcloud"`. Оберіть `"Nextcloud"`.
  5. Перевірте, що налаштування збереглося, і у `"Sync Location"` тепер відображається `"Nextcloud"`.

- [ ] **Тест: Синхронізація сейвів та автосинхронізація**
  1. Активуйте опцію `Auto-sync saves after backup` в налаштуваннях сейвів.
  2. Створіть резервну копію (backup) будь-якого сейву в меню сейвів.
  3. Переконайтеся, що після завершення локального бекапу автоматично запускається автосинхронізація на вибрану локацію `"Nextcloud"`, і файли успішно завантажуються.
  4. Спробуйте запустити відновлення (Restore) сейву, переконайтеся, що список бекапів також зчитується з вибраного джерела.

- [ ] **Тест: Автоматичне скидання активного джерела при видаленні**
  1. Перейдіть у `Tools -> Settings -> Sources`.
  2. Оберіть `"Nextcloud"` та видаліть його.
  3. Перейдіть у `Tools -> Settings -> WebDAV` (WebDAV Settings).
  4. Переконайтеся, що активна локація `"Sync Location"` автоматично змінилася на `"None"`.

## 8. Мережеві джерела WebDAV, FTP, HTTP та статус-бар (v0.13.220)

- [ ] **Тест: Зсув батареї у статус-барі**
  1. Запустіть Sphaira та перевірте верхню частину екрана.
  2. Переконайтеся, що відстань між годинником та відсотками заряду батареї візуально збільшилась (зсув `start_x` змінено на `94`).
  3. Підключіть консоль до зарядного пристрою та перевірте, чи іконка блискавки/індикатор заряджання не накладаються на годинник при 100% заряді.

- [ ] **Тест: Додавання джерел з різними протоколами**
  1. Перейдіть до Налаштування (Settings) -> Sources -> + Add network location або File Browser -> Sources -> Add network location.
  2. Переконайтеся, що з'являється спливаючий список вибору протоколу з 4 варіантами: `Samba (SMB)`, `WebDAV`, `FTP`, `HTTP`.
  3. Створіть джерело `WebDAV` (наприклад, `http://192.168.1.100/dav`), введіть логін та пароль. Переконайтеся, що воно з'явилося у списку.
  4. Створіть джерело `FTP` (наприклад, `192.168.1.100` з портом `21` або `2121`), введіть облікові дані.
  5. Створіть джерело `HTTP` (наприклад, `http://192.168.1.100/files`). Переконайтеся, що шлях автоматично доповнюється `http://`.
  6. Перевірте, що в опціях файлового браузера Advanced більше немає пунктів `Mount` та `Add network location` (вони повністю видалені).

- [ ] **Тест: Видалення джерел через налаштування**
  1. Перейдіть у Налаштування -> Sources.
  2. Оберіть раніше створене джерело та натисніть `A`.
  3. Перевірте появу вікна підтвердження: `"Delete this network location?"` з опціями `"No"` та `"Yes"`.
  4. Оберіть `"Yes"` та перевірте появу повідомлення `"Location deleted successfully!"` та оновлення списку (джерело має зникнути).

- [ ] **Тест: Оновлення опції Upload**
  1. Виберіть файл на SD-карті та відкрийте додаткові опції (`Advanced`).
  2. Переконайтеся, що назву пункту змінено на `"Upload to network location"`, а його опис став `"Upload the selected file(s) to a configured network storage."`.
  3. Перевірте запуск діалогового вікна вибору локації та перевірте, що при відсутності локацій з'являється повідомлення: `"No network locations configured! Add one in Settings."`.

## 7. Мережеві джерела Samba (SMB) у файловому менеджері (v0.13.219)

- [ ] **Тест: Додавання та монтування SMB джерела**
  1. Відкрийте File Browser -> Advanced -> Add network location.
  2. Послідовно введіть параметри вашого локального Samba сервера (назва, IP, назва спільної папки/share, юзернейм, пароль).
  3. Перейдіть до Sources -> Mount та оберіть вашу нову SMB-локацію.
  4. Переконайтеся, що підключення пройшло успішно (з'являється повідомлення "Connecting to SMB...") і ви бачите вміст спільної папки у списку.
  5. Перевірте, що при невдалому підключенні (наприклад, невірний IP чи пароль) з'являється інформативне повідомлення про помилку: "Failed to connect to SMB server!".

- [ ] **Тест: Відтворення медіа з SMB через NXMP**
  1. Перейдіть на змонтоване SMB-джерело.
  2. Знайдіть медіафайл (відео mp4/mkv або аудіо) та натисніть на нього.
  3. Оберіть пункт "Play with NXMP".
  4. Переконайтеся, що NXMP успішно запускається та програє файл, використовуючи переданий оригінальний мережевий URL (з авторизацією).
  5. Повторіть тест із пробілами та символами `@`, `:`, `%`, `#` у паролі, назві share або шляху до файла.

- [ ] **Тест: SMB залишається доступним лише для читання**
  1. На SMB-джерелі переконайтеся, що Paste, Delete, Rename, Create File і Create Folder заблоковані.
  2. Увімкніть "Ignore read only" і повторіть перевірку: операції запису на SMB мають залишитися заблокованими.
  3. Переконайтеся, що Copy з SMB на SD та встановлення підтримуваного пакета з SMB залишаються доступними.

- [ ] **Тест: Повторне підключення та зміна облікових даних**
  1. Кілька разів виконайте підключення з неправильним паролем, після чого підключіться з правильним — застосунок не повинен зависати або завершуватися через нестачу ресурсів.
  2. Створіть два записи з однаковими server/share, але різними користувачами або паролями, і переконайтеся, що перемикання створює нову сесію, а не використовує попередню авторизацію.

- [ ] **Тест: Демонтаж та очищення ресурсів**
  1. Перебуваючи в File Browser на SMB джерелі, перемкніть джерело на SD-карту або закрийте File Browser.
  2. Переконайтеся, що у логах чи системі `g_smb2fs` було успішно розмонтовано та видалено (лічильник посилань `g_smb_ref_count` скинувся).

## 6. Runtime-каталог і локалізовані описи sysmodules (v0.13.217)

- [ ] **Тест: Збірка оновленого офлайн каталогу у Sphaira**
  1. Скомпілюйте проект Sphaira у WSL за допомогою `make`.
  2. Перевірте, що скомпільований бінарник `kefir-hub.nro` містить у своїй вбудованій romfs файл `assets/romfs/modules/homebrew_sysmodules.json` з 17 verified модулями.
  3. Скопіюйте `kefir-hub.nro` на консоль та запустіть.
  4. Перейдіть до `Module Manager` та перевірте, що verified-модулі `pad-macro`, `sys-triplayer`, `NSParentalControl` і `nx-ovlreloader` коректно розпізнаються за Title ID.
  5. Перевірте, що `0100000000000035` не визначається як homebrew `sys-ftpd-light`; правильний homebrew Title ID — `420000000000000E`.
  6. Перемкніть мову Kefir Hub між English та Українська й перевірте локалізовані описи відомих модулів у підзаголовку.
  7. Видаліть `/config/kefir/cache/homebrew_sysmodules.txt`, вимкніть Wi-Fi та повторно відкрийте Module Manager: модулі й описи мають завантажитися з RomFS без помилки.

  3. Перевірте, що процес не переривається миттєво з фатальною помилкою, а намагається обробити решту файлів у черзі.

## 2. Керування сховищами MTP (v0.13.206 — v0.13.208)

- [ ] **Тест S5 / id 31: Налаштування та кастомізація дисків MTP**
  1. Перейдіть до `Settings` -> `Network settings` -> `MTP storages`.
  2. Спробуйте вимкнути тумблер `Show Install folder` або `Show microSD card`.
  3. Задайте кастомне ім'я для `microSD card name` та `Install folder name` (через клавіатуру `swkbd`).
  4. Увімкніть MTP, підключіть консоль до ПК та перевірте у Провіднику Windows:
     - Відображаються лише увімкнені сховища.
     - Вони мають задані вами кастомні імена (або "Default" / стандартні назви, якщо поле очищене).

- [ ] **Тест S5.1: Запобігання запуску MTP без сховищ**
  1. Вимкніть усі сховища в `MTP storages` (microSD card та Install folder).
  2. Спробуйте увімкнути тумблер `MTP` у Network settings.
  3. Перевірте, що з'являється нотифікація `"No MTP storages enabled"`, а тумблер MTP автоматично перемикається назад у стан **Off**.

- [ ] **Тест S6 / id 37: Диск розшифрованих сейвів «Saves (read-only)»**
  1. Перейдіть у `MTP storages` та увімкніть тумблер `Show Saves (read-only)`.
  2. Увімкніть MTP, підключіть консоль до ПК.
  3. Перевірте появу диска `Saves (read-only)`.
  4. Перевірте ієрархію: `/Назва_Гри [TitleID]/Account <нікнейм користувача> | BCAT | Device | Cache/файли_сейва`.
  5. Спробуйте скопіювати файли сейва з консолі на ПК — копіювання має пройти успішно.
  6. Спробуйте записати новий файл, видалити або перейменувати щось на диску сейвів з ПК — операція має повернути помилку відхилення доступу (read-only) і не викликати краш консолі.
  7. Запустіть гру на консолі і спробуйте з ПК відкрити її сейв. Перевірте, що доступ обмежено лише для цієї запущеної гри (повертає помилку блокування), тоді як інші сейви залишаються доступними.

## 4. Передача ігор через USB (PC Install) (v0.13.210 — v0.13.212)

- [ ] **Тест DBI: Розмір файлів та сумісність**
  1. Запустіть `dbibackend-qt` на ПК (версії v0.13.210 або новішої).
  2. Відкрийте меню `PC Install (USB)` у Sphaira та підключіть USB кабель.
  3. Перевірте, що в списку надісланих файлів відображаються їхні розміри, а також коректно розраховано сумарний розмір черги та вільне місце на NAND/SD.
  4. Перевірте сумісність: спробуйте підключитися за допомогою оригінального DBI backend (python-клієнт CLI або інші сторонні клієнти). Перевірте, що передача списку файлів проходить успішно, програма не крашиться і сумісність не порушена.

- [ ] **Тест id 57: Автопрокрутка журналу черги**
  1. Запустіть встановлення черги ігор через USB.
  2. Спостерігайте за журналом встановлення внизу екрана: екран має автоматично прокручуватися вниз до останнього доданого рядка без вашого втручання.
  3. Прокрутіть журнал вгору вручну стіком або пальцем — автопрокрутка має призупинитися, щоб дозволити вам прочитати попередні повідомлення. Прокрутіть назад до самого низу — автопрокрутка повинна відновитися.

- [ ] **Тест id 58: Кнопка B в черзі після завершення**
  1. Виберіть декілька ігор у черзі встановлення та почніть процес.
  2. Після завершення (екран `Summary`) натисніть `B`. Якщо USB-сесія все ще активна, кнопка `B` має повернути вас до екрана `ReviewQueue` зі збереженим списком ігор для можливого вибору та встановлення тих, які ви пропустили.
  3. Якщо з'єднання впало або виникла фатальна помилка сесії (`fatal_session_error`), перевірте, що кнопка `B` на екрані Summary/Cancelled відразу закриває меню і повертає вас до Tools без зависання на 3 секунди.

- [ ] **Тест id 59: Центрування тексту очікування та обрізання назв ігор**
  1. Відкрийте `PC Install (USB)`. Перевірте, що повідомлення `"Waiting for PC connection..."` не вилазить за межі екрана та розташоване рівно по центру.
  2. Запустіть встановлення гри з дуже довгою назвою. Перевірте, що назва гри коректно обрізається (кліпується) і не накладається зверху на смужку прогресу чи швидкість.
