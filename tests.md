# Інструкція для тестування змін на реальній консолі (v0.13.198 — v0.13.217)

Цей файл містить перелік живих тестів, які необхідно виконати на реальній консолі Nintendo Switch для підтвердження коректності внесених змін у версіях з **v0.13.198** по поточну **v0.13.217**.

---

## 6. Runtime-каталог і локалізовані описи sysmodules (v0.13.217)

- [ ] **Тест: Збірка оновленого офлайн каталогу у Sphaira**
  1. Скомпілюйте проект Sphaira у WSL за допомогою `make`.
  2. Перевірте, що скомпільований бінарник `kefir-hub.nro` містить у своїй вбудованій romfs файл `assets/romfs/modules/homebrew_sysmodules.json` з 17 verified модулями.
  3. Скопіюйте `kefir-hub.nro` на консоль та запустіть.
  4. Перейдіть до `Module Manager` та перевірте, що verified-модулі `pad-macro`, `sys-triplayer`, `NSParentalControl` і `nx-ovlreloader` коректно розпізнаються за Title ID.
  5. Перевірте, що `0100000000000035` не визначається як homebrew `sys-ftpd-light`; правильний homebrew Title ID — `420000000000000E`.
  6. Перемкніть мову Kefir Hub між English та Українська й перевірте локалізовані описи відомих модулів у підзаголовку.
  7. Видаліть `/config/kefir/cache/homebrew_sysmodules.txt`, вимкніть Wi-Fi та повторно відкрийте Module Manager: модулі й описи мають завантажитися з RomFS без помилки.
  8. Увімкніть Wi-Fi, відкрийте Module Manager і перевірте появу валідного кешу `/config/kefir/cache/homebrew_sysmodules.txt`; файл `.download` після завершення залишатися не повинен.
  9. Тимчасово пошкодьте кеш індексу й відкрийте меню без інтернету: застосунок має проігнорувати кеш і використати вбудований каталог.


> [!NOTE]
> Будь ласка, відмічайте успішно пройдений тест позначкою `[x]`. Залишайте коментарі під тестами, якщо виявили дефекти чи дивну поведінку.

## 1. Резервне копіювання сейвів та WebDAV (v0.13.201 — v0.13.204)

- [ ] **Тест S1: Автосинхронізація з кастомної локації**
  1. Перейдіть до `Settings` -> `Network settings` -> `WebDAV` та перевірте, що дані вашого WebDAV-сервера налаштовані правильно.
  2. Перейдіть до `Saves`, змініть `Location` (шлях для бекапів) на stdio-носій (наприклад, підключену флешку USB/HDD через `ums0:/...` або кастомну Recent-теку).
  3. Створіть новий бекап сейва гри.
  4. Перевірте лог та ваш WebDAV-сервер: щойно створений ZIP-архів має бути завантажений у правильний каталог на сервері без помилок.

- [ ] **Тест S4: Стійкість синхронізації при розриві мережі**
  1. Запустіть повну синхронізацію (`Sync with remote`) за наявності декількох (3 або більше) файлів для передачі.
  2. Під час передачі другого файлу вимкніть Wi-Fi на консолі (або вимкніть точку доступу).
  3. Перевірте, що процес не переривається миттєво з фатальною помилкою, а намагається обробити решту файлів у черзі.
  4. Після закінчення черги має з'явитися вікно повідомлення: `Sync finished with N failed transfers. See log for details.` (де N — кількість файлів, які не вдалося завантажити).
  5. Перевірте в `log.txt`, що всі помилки зафіксовано, а на SD-карті не залишилося сміттєвих `.temp`-файлів.

- [ ] **Тест S4.1: Скасування синхронізації кнопкою B**
  1. Запустіть синхронізацію сейвів.
  2. Натисніть кнопку `B` для скасування посеред процесу (наприклад, під час завантаження файлу).
  3. Перевірте, що з'являється ErrorBox із кодом помилки скасування `Result_TransferCancelled`.

- [ ] **Тест S2 + S3: Чесні підказки в інтерфейсі**
  1. Перевірте підказку (tooltip) біля пункту `Sync with remote` в меню сейвів. Вона має чітко зазначати, що синхронізуються лише бекапи з microSD (тека `/dumps` та `/switch/DBI/saves`).
  2. Перевірте підказку біля пункту `Location`. Вона повинна чесно пояснювати, що ігрові сейви завжди пишуться у DBI-форматі в `/switch/DBI/saves` на обраному носії, а обрана папка використовується для системних сейвів та пошуку старих бекапів.

## 2. Керування сховищами MTP (v0.13.206 — v0.13.208)

- [ ] **Тест S5 / id 31: Налаштування та кастомізація дисків MTP**
  1. Перейдіть до `Settings` -> `Network settings` -> `MTP storages`.
  2. Спробуйте вимкнути тумблер `Show Install folder` або `Show microSD card`.
  3. Задайте кастомне ім'я для `microSD card name` та `Install folder name` (через клавіатуру `swkbd`).
  4. Увімкніть MTP, підключіть консоль до ПК та перевірте у Провіднику Windows:
     - Відображаються лише увімкнені сховища.
     - Вони мають задані вами кастомні імена (або "Default" / стандартні назви, якщо поле очищене).

- [ ] **Тест S5.1: Запобігання запуску MTP без сховищ**
  1. Вимкніть усі сховища в `MTP storages` (microSD card та Install folder).
  2. Спробуйте увімкнути тумблер `MTP` у Network settings.
  3. Перевірте, що з'являється нотифікація `"No MTP storages enabled"`, а тумблер MTP автоматично перемикається назад у стан **Off**.

- [ ] **Тест S6 / id 37: Диск розшифрованих сейвів «Saves (read-only)»**
  1. Перейдіть у `MTP storages` та увімкніть тумблер `Show Saves (read-only)`.
  2. Увімкніть MTP, підключіть консоль до ПК.
  3. Перевірте появу диска `Saves (read-only)`.
  4. Перевірте ієрархію: `/Назва_Гри [TitleID]/Account <нікнейм користувача> | BCAT | Device | Cache/файли_сейва`.
  5. Спробуйте скопіювати файли сейва з консолі на ПК — копіювання має пройти успішно.
  6. Спробуйте записати новий файл, видалити або перейменувати щось на диску сейвів з ПК — операція має повернути помилку відхилення доступу (read-only) і не викликати краш консолі.
  7. Запустіть гру на консолі і спробуйте з ПК відкрити її сейв. Перевірте, що доступ обмежено лише для цієї запущеної гри (повертає помилку блокування), тоді як інші сейви залишаються доступними.

## 3. UX покращення MTP, WebDAV та File Browser (v0.13.209)

- [ ] **Тест id 43: Попап прогресу копіювання через MTP**
  1. Підключіть консоль по MTP та почніть копіювати будь-який великий файл (НЕ ігровий пакет для встановлення) на SD-карту або з неї.
  2. Перевірте, що на екрані консолі з'являється не-модальний попап `"Copying via MTP"` із відображенням назви файлу, швидкості та прогресу передачі.
  3. Натисніть `L3` для згортання — попап має перетворитися на маленький індикатор у кутку екрана, зберігаючи можливість навігації по меню.
  4. Скопіюйте серію невеликих файлів, перевірте стійкість вікна до швидкого перемикання файлів (попап не повинен блимати чи різко зникати завдяки 1.5-секундній затримці).

- [ ] **Тест S7 / id 47: Меню налаштувань WebDAV**
  1. Перейдіть у `Network settings` -> `WebDAV`. Перевірте, що воно відкриває окремий Sidebar праворуч.
  2. Перевірте введення `Server address`: спробуйте ввести адресу без схеми (`dav.example.com`) або з `https://` — вона має зберегтися як канонічна адреса HTTPS WebDAV. Спроба ввести `http://` має бути відхилена з повідомленням про помилку.
  3. Перевірте введення пароля — він має показуватись як `********` для захисту приватности.

- [ ] **Тест S8: Швидкий вибір джерел у File Browser**
  1. Відкрийте File Browser, натисніть `X` (або увійдіть до контекстного меню) та оберіть пункт `Sources`.
  2. Перевірте наявність списку всіх підключених носіїв та мережевих папок. Поточне активне джерело має бути позначене стрілкою `->`.
  3. Перемкніться на інше джерело та перевірте успішність переходу.

## 4. Передача ігор через USB (PC Install) (v0.13.210 — v0.13.212)

- [ ] **Тест DBI: Розмір файлів та сумісність**
  1. Запустіть `dbibackend-qt` на ПК (версії v0.13.210 або новішої).
  2. Відкрийте меню `PC Install (USB)` у Sphaira та підключіть USB кабель.
  3. Перевірте, що в списку надісланих файлів відображаються їхні розміри, а також коректно розраховано сумарний розмір черги та вільне місце на NAND/SD.
  4. Перевірте сумісність: спробуйте підключитися за допомогою оригінального DBI backend (python-клієнт CLI або інші сторонні клієнти). Перевірте, що передача списку файлів проходить успішно, програма не крашиться і сумісність не порушена.

- [ ] **Тест id 57: Автопрокрутка журналу черги**
  1. Запустіть встановлення черги ігор через USB.
  2. Спостерігайте за журналом встановлення внизу екрана: екран має автоматично прокручуватися вниз до останнього доданого рядка без вашого втручання.
  3. Прокрутіть журнал вгору вручну стіком або пальцем — автопрокрутка має призупинитися, щоб дозволити вам прочитати попередні повідомлення. Прокрутіть назад до самого низу — автопрокрутка повинна відновитися.

- [ ] **Тест id 58: Кнопка B в черзі після завершення**
  1. Виберіть декілька ігор у черзі встановлення та почніть процес.
  2. Після завершення (екран `Summary`) натисніть `B`. Якщо USB-сесія все ще активна, кнопка `B` має повернути вас до екрана `ReviewQueue` зі збереженим списком ігор для можливого вибору та встановлення тих, які ви пропустили.
  3. Якщо з'єднання впало або виникла фатальна помилка сесії (`fatal_session_error`), перевірте, що кнопка `B` на екрані Summary/Cancelled відразу закриває меню і повертає вас до Tools без зависання на 3 секунди.

- [ ] **Тест id 59: Центрування тексту очікування та обрізання назв ігор**
  1. Відкрийте `PC Install (USB)`. Перевірте, що повідомлення `"Waiting for PC connection..."` не вилазить за межі екрана та розташоване рівно по центру.
  2. Запустіть встановлення гри з дуже довгою назвою. Перевірте, що назва гри коректно обрізається (кліпується) і не накладається зверху на смужку прогресу чи швидкість.

## 5. UX покращення Module Manager та тач-навігації Settings (v0.13.213)

- [ ] **Тест id 44: Візуальне розділення станів у Module Manager**
  1. Перейдіть до `Tools` -> `Module Manager`.
  2. Перевірте, що для кожного модуля праворуч відображається два окремі стани:
     - `Now: On` (зелений) / `Now: Off` (сірий)
     - `After reboot: Enabled` (жовтий) / `After reboot: Disabled` (сірий)
  3. Перевірте, що натискання `A` (Toggle running) змінює стан `Now`, але НЕ змінює стан `After reboot` (для динамічних модулів).
  4. Перевірте, що натискання `Y` (Toggle autostart) змінює стан `After reboot`, але НЕ змінює стан `Now`.
  5. Спробуйте натиснути `A` на reboot-only модулі (наприклад, Mission Control): перевірте, що з'являється нотифікація `"This module applies after reboot. Use autostart."` і стан `Now` не змінюється.

- [ ] **Тест id 44.1: Реєстр описів модулів modules.json**
  1. Перевірте, що в підзаголовку (під назвою модуля вгорі) показується детальний локалізований опис вибраного модуля (українською, якщо мова консолі українська).
  2. Перевірте, що на SD-карті у `/config/kefir/modules.json` створено файл з описами за замовчуванням.
  3. Спробуйте вручну додати опис для будь-якого іншого модуля в цей файл та перезавантажити меню (X) — новий опис має підтягнутися.
  4. Для сторонніх невідомих модулів перевірте, що підзаголовок показує: `"No description provided"`.

- [ ] **Тест id 46: Геометрія списку та рамка виділення**
  1. Перейдіть до `Module Manager` та подивіться на список модулів.
  2. Перевірте, що список піднято вище, ніж у попередніх версіях, і перший рядок починається одразу під легендою кнопок, без великої порожнечі.
  3. Прокрутіть список та перевірте рамку фокусу (виділення) на першому, середньому та останньому елементах: рамка фокусу має бути повністю видимою з усіх чотирьох боків (не обрізатися по краях viewport).

- [ ] **Тест id 48: Сенсорна навігація в головному Settings**
  1. Перейдіть у `Settings`.
  2. Здійснюйте тапи по категоріях у лівій колонці. Перевірте, що категорія миттєво змінюється і права колонка оновлюється.
  3. Здійсніть тап по параметру в правій колонці. Перший тап має перевести фокус на цей параметр (виділити його рамкою фокусу), але НЕ відкривати / змінювати його.
  4. Повторний тап по вже виділеному параметру в правій колонці має активувати його (відкрити Sidebar, OptionBox або swkbd).
  5. Перевірте, що немає випадків, коли тач у лівій чи правій колонці ігнорується або реєструється в іншій колонці.
