# Game cards

What Kefir Hub does with the game card in the console's card slot.

**Where:** [[Tools]] → [[Game Tools]] → [[Games]]

This version has no separate game card menu: you cannot install a game card's contents to the console from Kefir Hub.

## Find the game card {#find}

1. Insert the game card.
2. Open [[Tools]] → [[Game Tools]] → [[Games]].
3. The game card is at the top of the list. Its icon has an outline and a GC badge.

<!-- shot: install-gamecard-games-row | Games list with the game card row at the top, GC badge and outline -->

## Dump the game card to NSP files {#dump}

1. Highlight the game card in [[Games]] and press **+**.
2. Select [[Dump]] and choose what to dump, for example [[Dump All]].
3. Choose where to save the files.

The dump is described in [Games](../games.md). Dump settings are in [[Games]] → **+** → [[Advanced options]] → [[Dump options]].
