# Дорожня карта

Що Kefir Hub отримав нещодавно і що заплановано далі. Список може змінюватися: пункти переносяться, зменшуються або зникають після перевірки на справжніх консолях.

!!! note
    Пункт у списку — це план, а не обіцянка. Пункти, що зачіпають системні дані, виходять лише після тесту на залізі.

## Нещодавно додано {#shipped}

| Можливість | Що робить |
|---|---|
| Очищення системи | Один список прапорців видаляє старі оновлення, осиротілий вміст, плейсхолдери, непотрібні квитки тощо й показує, скільки звільнив кожен крок. |
| Системна інформація | Усі дані про консоль, Atmosphère, SD-карту, батарею й обладнання в згрупованих таблицях. Див. [Системні інструменти](system-tools.md#system-information). |
| Патчі ігор | Зняти вимогу привʼязаного акаунта, дозволити знімки екрана й запис відео — під час встановлення або пізніше для встановленої гри. |
| Мова, привʼязана до пакета перекладу | Пакет перекладу може примусово задати мову гри. Мову можна задати і вручну для кожної встановленої гри. |
| Перенесення ігор між двома консолями | Надсилайте ігри, оновлення й DLC з однієї консолі на іншу через Wi-Fi або кабель. Див. [Перенесення між консолями](console-transfer.md). |
| Моди | Розмір модів у картці гри, видалення модів і папка модів для кожної гри через MTP. |
| Збереження | Перевірка бекапів, перегляд бекапу лише для читання, автоматичний бекап перед видаленням збереження, відновлення папок із JKSV або Checkpoint. |
| Файловий менеджер | Hex-перегляд і розпакування архівів RAR, 7z, xz, tar і gz. |
| Видалення homebrew | Видалення застосунку разом із його папкою та форвардерами. |
| ПК-встановлення при підключенні | Після підключення кабелю Hub шукає на ПК застосунок для встановлення й відкриває список. |
| Сторінка першого запуску | Повна сторінка мовою консолі з першими кроками. |

## Заплановано і в роботі {#planned}

### Онлайн-гра {#online}

| Можливість | Стан | Що робить |
|---|---|---|
| Nextendo всередині | Заплановано | Онлайн-гра Nextendo на emuMMC без жодного натискання. Розділ Nextendo в налаштуваннях Kefir показує режим, підтримувану прошивку й підтримувані ігри. Опція для sysNAND планується лише для Semi-stock. |

### Ігри та встановлення {#games}

| Можливість | Стан | Що робить |
|---|---|---|
| Оновлення ігор | Дослідження | Знаходити встановлені ігри з новішим оновленням або DLC і завантажувати їх через застосунок для завантаження. |
| Потрібна новіша прошивка | Відкладено | Попереджати, коли грі потрібен новіший SDK, ніж має прошивка, і скидати потрібну версію. |
| Невдалі встановлення | Заплановано | Після встановлення застосунок на ПК показує файли з помилкою. Hub пропонує перезапуститися в Title Mode і продовжити саме з цими файлами. |
| Багато дрібних файлів через MTP | Заплановано | Підказка запакувати папку, рядок загального прогресу й розпакування архівів, скинутих через MTP. |
| Моди | У роботі | Автоматично встановлювати моди, коли папку гри з модами копіюють через MTP. Пакувати моди в `romfs.bin`. |
| Перепакування з модами | У роботі | У списку ігор перебудувати гру в NSP з модом, оновленням і DLC. |
| Деталі гри | Заплановано | Сторінка лише для читання з даними NACP гри (вікові рейтинги, знімки екрана й відео, розміри збережень) і перевірка форвардера перед встановленням. |

### Догляд за консоллю {#console}

| Можливість | Стан | Що робить |
|---|---|---|
| Індикатор батареї й майстер калібрування | У роботі | Читати мікросхему батареї, робити її бекап, відновлювати та покроково калібрувати індикатор. Підтримує збільшені батареї. Див. [Калібрування батареї](battery-calibration.md). |
| Менеджер памʼяті | У роботі | Кільцева діаграма того, що займає microSD і внутрішню памʼять, з карткою для кожної частини. |
| Ремонт SD-карти | Дослідження | Виправити карту, з якої ігри перестали запускатися після копіювання файлів на більшу карту. |
| Синхронізація Joy-Con і Wi-Fi | Заплановано | Копіювати Bluetooth-парування й мережі Wi-Fi між sysMMC і emuMMC. |
| Кольори консолі | Заплановано | Змінювати кольори, які система показує для корпусу Switch Lite і Joy-Con. |
| Зміна регіону | Дослідження | Змінити китайську консоль на глобальний регіон зі створенням бекапу. Потрібен тест на справжній консолі. |

### Hub {#hub}

| Можливість | Стан | Що робить |
|---|---|---|
| Журнал активності | Заплановано | Час гри за кожною грою: загальний час, запуски, перша й остання гра, часова шкала. |
| Екскурсія замість Kefir Updater | Заплановано | Коли ви відкриваєте Kefir Updater, Hub пояснює, що тепер Kefir оновлює він, і веде вас до сторінки оновлення. |
