# [[Saves]]

Резервні копії збережень ігор на карту пам'яті (або USB-накопичувач), відновлення, видалення і копія на сервері WebDAV. Kefir Hub також знаходить і відновлює резервні копії, зроблені в DBI, JKSV і Checkpoint.

**Де:** [[Tools]] → [[Game Tools]] → [[Saves]]

<!-- shot: saves-list | Saves screen, Installed Games tab, several game tiles, subheading with user name and "Account" -->

## Як влаштований екран
На екрані три вкладки. Перемикайте їх кнопками **L** і **R** або торкніться вкладки.

| Вкладка | Що показує |
|---|---|
| [[Installed Games]] | Усі встановлені ігри — зі збереженням чи без. |
| [[Deleted Games]] | Збереження, які лишилися на консолі від видалених ігор. |
| [[Backups]] | Резервні копії, знайдені на карті пам'яті, згруповані за програмою, що їх зробила: [[Kefir Hub]], [[DBI]], [[JKSV]], [[Checkpoint]], [[Other]]. |

Рядок під заголовком показує, чиї збереження і яких типів зараз у списку. Спочатку видно тільки звичайні збереження ігор (тип `Account`) поточного користувача.

### Плашки типів збережень

Плитки ігор показують невеликі кольорові плашки для фактичних типів збережень у тому ж стилі, що й на екрані [[Games]]:

| Плашка | Значення |
|---|---|
| `Acc` | Звичайні збереження користувача, прив'язані до профілю на консолі. |
| `Device` | Загальноконсольне збереження пристрою, спільне для всіх користувачів (наприклад, в Animal Crossing). |
| `BCAT` | Фонова доставка контенту (події розповсюдження, оновлення контенту). |
| `Cache` | Збереження в кеш-пам'яті. |
| `Temp` | Тимчасові дані збереження під час гри. |
| `Sys` / `SysBCAT` | Системні збереження консолі. |

Ігри з кількома типами збережень (наприклад, Device і BCAT) показують плашки для кожного наявного типу. Кілька слотів однакового типу (наприклад, для різних профілів користувачів) об'єднуються в одну плашку. Встановлені ігри, для яких ще немає збережень, не мають плашок типів. У режимі списку плашки розташовуються в рядку ліворуч від розміру збереження. Назви плашок однакові для всіх мов інтерфейсу: `Acc`, `Device`, `BCAT`, `Cache`.

Кнопки:

- **A** — дії для збереження під курсором (або для всіх позначених);
- **X** — позначити чи зняти позначку; **Y** — інвертувати вибір; **B** — зняти позначки, потім вийти;
- **+** — [[Save Options]].

Якщо відкрити екран із подробиць гри ([[Backup and restore]], див. [Ігри](games.md#manage-save-slots)), він показує лише цю гру, для всіх користувачів і всіх типів збережень, без вкладок.

## Вибрати користувачів і типи збережень
1. Натисніть **+**.
2. [[Accounts]]: позначте [[All Accounts]] або окремих користувачів.
3. [[Data Types]]: позначте типи збережень, які треба показати. Збереження `System` показуються окремо: якщо позначити `System`, інші типи ховаються.

## Створити резервну копію
1. На вкладці [[Installed Games]] чи [[Deleted Games]] наведіть на гру (або позначте кілька кнопкою **X**).
2. Натисніть **A** і виберіть [[Create backup]]. (Або **+** → [[Backup]].)
3. Відкриються [[Backup Options]]:
    - [[Location]] — куди писати. Типово `sd://dumps`. [[Choose Folder...]] дає вибрати іншу папку на карті пам'яті чи на USB-накопичувачі; останні 5 вибраних папок запам'ятовуються.
    - [[Auto-sync after backup]] — одразу вивантажити нову копію на WebDAV (див. [Синхронізація з WebDAV](#sync-backups-with-webdav)).
    - [[ACCOUNTS]] — чиї збереження копіювати (видно, якщо на консолі кілька користувачів). Усі відповідні типи збережень (Account, Device, BCAT та Cache) додаються до пакета автоматично.
4. Виберіть [[Start Backup]] угорі.

<!-- shot: saves-backup-options | Backup Options sidebar: Start Backup, Location sd://dumps, Auto-sync after backup, ACCOUNTS with two users -->

Наприкінці з'явиться [[Backup successful!]].

Kefir Hub копіює лише змінені збереження. Він порівнює кожне збереження з його найновішою копією у вибраному [[Location]]. Якщо збереження не змінилося від тієї копії, Kefir Hub його пропускає, тож у папці не буде двох однакових копій. Якщо нічого не змінилося, з'явиться [[All selected saves are already up to date.]] Порожні збереження теж пропускаються; якщо нічого не записано, ви побачите [[No save data found for this title]].

## Де лежать резервні копії
Типова папка: `/dumps` на карті пам'яті.

| Збереження | Файл |
|---|---|
| Збереження ігор (усі типи, крім системних) | `/dumps/<Назва гри>/<РРРРММДД>/<Title ID>_<літера типу>_<РРРРММДДггххсс>_<слот>.zip` |
| Системні збереження | `/dumps/Save System/<ID збереження>/<РРРР.ММ.ДД @ гг.хх.сс>.zip` |
| Страхувальні копії, що робляться під час відновлення | `/dumps/recovery/<дата>_<час>_<ID збереження>_<номер>/recovery.zip` |

Літера типу: `A` (збереження користувача), `B` (BCAT), `D` (пристрою), `T` (тимчасове) або `C` (кеш). Збереження ігор мають той самий формат ZIP, що й у DBI, тож DBI їх відновить, а Kefir Hub відновить копії DBI.

Якщо вибрати інше [[Location]], така сама структура створиться всередині тієї папки.

## Копії з інших програм
Вкладка [[Backups]] і кожне відновлення шукають копії в цих папках на карті пам'яті:

| Програма | Папки |
|---|---|
| Kefir Hub | `/dumps` |
| DBI | `/switch/DBI/saves`, `/DBISaves` |
| JKSV | `/JKSV`, `/switch/JKSV` |
| Checkpoint | `/switch/Checkpoint/saves`, `/Checkpoint/saves` |

Копії DBI і Kefir Hub — це файли ZIP. Копії JKSV і Checkpoint — папки; відновлюються вони так само.
Копії JKSV, Checkpoint і старих версій DBI не зберігають розмір збереження, тож щоб відновити таку копію для користувача,
у якого ще немає збереження цієї гри, гру треба встановити: Kefir Hub візьме розмір із неї.

Щоб Kefir Hub шукав ще в одній папці:

1. Відкрийте [[Tools]] → [[Settings]] → [[Saves]] → [[Save Backup Search Paths]].
2. Виберіть [[Add folder]] і вкажіть папку на карті пам'яті. Додати можна лише папки з карти пам'яті.

!!! tip
    Копії на USB-накопичувачі не з'являються на вкладці [[Backups]]. Щоб відновити таку, почніть відновлення з вкладки [[Installed Games]] і виберіть цей накопичувач у [[Location]].

## Відновити збереження
!!! warning
    Перед відновленням закрийте гру. Поки працює MTP (передача файлів на ПК через USB), відновлення не запуститься — спершу вимкніть MTP.

1. На вкладці [[Installed Games]] (чи [[Deleted Games]]) наведіть на гру й натисніть **A** → [[Restore]]. (Або **+** → [[Restore]].)
2. Відкриються [[Restore Options]]. У пункті [[Location]] виберіть папку з копіями. Типове розташування також шукає копії в налаштованій бібліотеці. Зміна розташування оновлює доступні джерела та параметри акаунтів.

    Перевірте [[Backup Source]]. Kefir Hub вибрано, якщо його копії доступні. Щоб використати копії іншої програми, виберіть її джерело. Джерело, вже вибране на вкладці [[Backups]], зберігається. Виберіть [[Start Restore]].
3. Для збереження користувача [[Restore for user]] запитає, якому користувачу його віддати. Копію одного користувача можна відновити іншому.
4. Якщо в цього користувача вже є збереження, підтвердіть ціль. Якщо в гри кілька слотів, виберіть потрібний у [[Select restore target slot]].
5. Якщо копій кілька, виберіть одну в [[Select backup]]. Копії впорядковано від найновішої, з датою й часом.
6. Підтвердіть останнє вікно кнопкою [[Yes]].

Перед перезаписом Kefir Hub зберігає поточне збереження як страхувальну копію в `/dumps/recovery/`. Після відновлення вікно покаже, де вона лежить. Наприкінці з'явиться [[Restore successful!]].

## Відновити з вкладки [[Backups]]
1. Відкрийте вкладку [[Backups]]. Кожна гра має плитку для кожного джерела копій. Плитка містить повний пакет цього джерела: збереження акаунтів, Device, BCAT і Cache.
2. Наведіть на плитку й натисніть **A**. Відкриється [[Backup Action]].
3. У [[Backup Action]] виберіть [[Restore]], щоб відновити повний пакет збережень (або виберіть [[Individual saves...]], щоб оглянути та відновити окремий слот збереження чи користувача). Продовжуйте, як у розділі [Відновити збереження](#restore-a-save), з кроку 3.

<!-- shot: saves-backup-group | Backups tab: unified game tiles representing complete save bundles -->

У [[Backup Action]] також є:

| Дія | Що робить |
|---|---|
| [[Restore]] | Відновлює всі наявні збереження з пакета цієї гри (або вибраний слот). |
| [[Verify integrity]] | Перевіряє всі ZIP цієї групи й показує пошкоджені. Копії-папки (RAW) перевірити не можна. |
| [[Delete older backups]] | Видаляє всі копії, крім найновішої в кожній групі. |
| [[Open in file browser]] | Відкриває папку з найновішою копією. |
| [[Individual saves...]] | Показує кожне збереження в пакеті окремо (за обліковим записом або типом збереження) для відновлення або видалення окремих слотів. |
| [[Select all backups for this user]] | Позначає копії цього користувача для всіх ігор (під час огляду збереження облікового запису). |
| [[Select all backups for this game]] | Позначає всі групи копій цієї гри. |
| [[Delete]] | Видаляє всі копії цієї групи з карти пам'яті. |

## Якщо в гри ще немає збереження
Якщо на консолі немає слота для цієї копії, Kefir Hub створить його й відновить у нього. Це працює для
збережень `Account` (вибраного користувача), `Device` і `BCAT`, лише основний слот. Розмір і власника слота
Kefir Hub бере:

- з самої копії, якщо це копія Kefir Hub або DBI (вони містять метадані збереження). Гру встановлювати не
  обов'язково. Коли ви встановите гру пізніше, вона використає відновлене збереження;
- з установленої гри, якщо копія — папка JKSV або Checkpoint (без метаданих).

Якщо в копії немає метаданих і гру не встановлено, відновлення зупиниться з повідомленням, яке називає гру
й просить її встановити.

Щоб відновити збереження видаленої гри, або залиште її збереження на консолі (воно лишається на вкладці [[Deleted Games]], і відновити можна там), або спершу встановіть гру знову.

## Відновити кілька збережень разом
Позначте кілька збережень (або кілька груп копій) і виберіть [[Restore]]. [[Restore for user]] один раз питає, якому користувачу віддати всі збереження; виберіть там [[Choose for each save]], щоб відповісти для кожного окремо. Якщо серед позначених є копії однієї гри від різних користувачів, питання ставиться для кожного збереження; у ньому видно гру, чия це копія і її дату. Віддайте кожну копію іншому користувачу або відновіть лише одну з них. Далі одне вікно показує всі збереження й куди вони підуть; підтвердіть його кнопкою [[Yes]]. Збереження відновлюються по одному: якщо одне не вдасться, попередні лишаться відновленими.

## Скасувати відновлення
Страхувальна копія з `/dumps/recovery/` — це звичайний ZIP збереження в тому стані, який був до відновлення.

Вона з'являється на вкладці [[Backups]] як ще один архів у групі [[Kefir Hub]] цієї гри.

1. Відкрийте вкладку [[Backups]]. Кожна гра має плитку для кожного джерела копій. Плитка містить повний пакет цього джерела: збереження акаунтів, Device, BCAT і Cache.
2. Знайдіть страхувальну копію в групі [[Kefir Hub]]. Її дата — це час, коли збереження востаннє записувалося
   перед відновленням, а не час самого відновлення, тож вона може бути не вгорі.
3. Відновіть її, як будь-яку іншу копію, див. [Відновити з вкладки копій](#restore-from-the-backups-tab).

## Видалити збереження з консолі
!!! note
    Перед видаленням Kefir Hub автоматично робить резервну копію кожного збереження (`AUTO - <користувач> - <дата>.zip`,
    вкладка [[Backups]]), тож випадково видалене збереження можна відновити. Якщо копію зробити не вдалося, збереження не видаляється.

1. На вкладці [[Installed Games]] чи [[Deleted Games]] наведіть на гру (або позначте кілька) і натисніть **A** → [[Delete]].
2. У [[Delete Options]] виберіть користувачів і типи збережень, потім [[Delete Saves]].
3. Підтвердіть кнопкою [[Delete]].

## Видалити резервні копії
- Однієї гри: вкладка [[Backups]], **A** на грі → виберіть рядок → [[Delete]].
- Лише старі: [[Delete older backups]] залишає найновішу копію в кожній групі.

Видалення копій прибирає файли ZIP з карти пам'яті, зокрема й копії DBI цієї гри.

## Синхронізація з WebDAV
Потрібне мережеве розташування WebDAV. Додайте його в [[Tools]] → [[Settings]] → [[Saves]] → [[Save sync location]] → [[+ Add network location]] або у файловому менеджері (див. [Файловий менеджер](file-browser.md)).

**Двостороння синхронізація:**

1. Позначте ігри, копії яких треба синхронізувати.
2. Натисніть **+** → [[Sync with remote]]. Якщо розташувань WebDAV кілька, виберіть одне в [[Select Sync Location]].
3. Копії, яких немає на сервері, вивантажуються туди; копії, яких немає на карті пам'яті, завантажуються на неї. Файли з однаковою назвою ніколи не перезаписуються.

Синхронізується лише бібліотека копій на карті пам'яті: `/dumps` і `/switch/DBI/saves`. На сервері копії лежать у папці `sphaira-saves`. Завантажені копії самі не застосовуються — потім скористайтеся [відновленням](#restore-a-save).

**Автоматичне вивантаження після кожної копії:** увімкніть [[Auto-sync after backup]] (у [[Backup Options]] або в налаштуваннях). Вивантажується лише новий ZIP — у розташування з [[Save sync location]] (або в перше розташування WebDAV, якщо його не задано).

**Копії із сервера під час відновлення:** увімкніть [[Include remote backups]] (у [[Restore Options]] або в налаштуваннях). Перед показом списку копій завантажуються ті, що є лише на сервері. Працює, коли на вкладці [[Installed Games]] чи [[Deleted Games]] вибрано одне збереження.

## Проблеми
**[[Please select only live saves or only backups.]]** Ви позначили водночас збереження з консолі й резервні копії. Позначте щось одне.

**[[No backups found for selected saves.]]** Для цієї гри й користувача не знайдено копій ні в [[Location]], ні в папках інших програм. Перевірте [[Location]] у [[Restore Options]] або додайте папку в [[Save Backup Search Paths]].

**[[Selected backup archive has changed or is no longer available.]]** Файл перемістили, видалили, або він не від цього збереження. Відкрийте [[Saves]] знову й виберіть копію ще раз.

**[[Application control data not found for installed title.]]** Kefir Hub не може створити збереження для невстановленої гри. Встановіть гру або запустіть її один раз.

**[[RAW container restore is unsupported.]]** Копія — це сирий образ збереження, а не ZIP чи папка. Kefir Hub його не відновить.

**[[Live save filesystem browsing is not currently supported.]]** [[Open in file browser]] працює лише для резервних копій, а не для збережень на консолі.

**[[No WebDAV network location configured for sync. Add one in settings.]]** Додайте розташування WebDAV, див. [Синхронізація з WebDAV](#sync-backups-with-webdav).

**[[Auto-sync failed!]]** Копію створено, але вивантажити її не вдалося. Перевірте мережу й розташування WebDAV, потім запустіть [[Sync with remote]].

**Повідомлення про MTP під час відновлення.** Вимкніть MTP (передачу файлів через USB) і закрийте гру, потім спробуйте ще раз.
