# [[Cheats]]

Завантаження чит-кодів для ігор, імпорт власних файлів читів, перегляд встановленого й видалення. Atmosphère завантажує чити з карти пам'яті під час запуску гри.

**Де:** [[Tools]] → [[Game Tools]] → [[Cheats]]

<!-- shot: cheats-menu | Cheats menu with all eight entries, Download Kefir Cheats focused -->

## Як працюють чити
Чити кожної гри — це текстовий файл, названий за **Build ID** гри (код, що змінюється з кожним оновленням гри):

`/atmosphere/contents/<title id>/cheats/<BUILD ID>.txt`

Файл читів працює лише для тієї версії гри, під яку його зроблено. Після оновлення гри старий файл уже не підходить — див. [Виправити чити після оновлення гри](#fix-cheats-after-a-game-update).

Kefir Hub встановлює, показує й видаляє файли читів. Вмикати чи вимикати окремі чити він не вміє — це робиться в самій грі через оверлей для читів.

## Встановити повний набір читів
1. Виберіть [[Download Kefir Cheats]] (чити для багатьох ігор) або [[Download 60FPS/GFX Cheats]] (чити на частоту кадрів, роздільність і графіку).
2. Підтвердіть кнопкою [[Download]].
3. Дочекайтеся повідомлення [[Cheats pack installed]].

Набір береться з проєкту switch-cheats-db і розпаковується в `/atmosphere`. Наявні файли читів з такими самими назвами перезаписуються. Потрібне з'єднання з інтернетом.

## Завантажити чити для однієї гри
1. Виберіть [[Download Exact Cheats]].
2. Відкриється список встановлених ігор. Наведіть на гру й натисніть **A**.
3. Kefir Hub визначить Build ID гри й завантажить відповідні чити. Build ID видно вгорі поруч із назвою гри.
4. Виберіть чити:
    - **A** — [[Toggle]] (позначити чит під курсором);
    - **X** — [[Select All]] (ще раз — зняти всі позначки);
    - **R** — [[Preview]] (переглянути код).
5. Натисніть **Y** ([[Download]]) і підтвердьте.

<!-- shot: cheats-select | Cheat list for one game: game name and Build ID at the top, three cheats ticked [X] -->

Нові чити додаються до наявного файлу читів гри; чити з такою самою назвою пропускаються. В одному файлі може бути щонайбільше 128 читів — більше Atmosphère не читає, тож зайві не встановлюються.

!!! tip
    Запустіть гру один раз, закрийте її, а тоді завантажуйте. Найнадійніше Kefir Hub визначає Build ID із запущеної або встановленої гри. Якщо не вдається, він шукає версію онлайн, а це для деяких ігор може дати хибний результат.

## Імпортувати файл читів
Для файлу `.txt` з читами, який ви скопіювали на карту пам'яті.

1. Виберіть [[Import From File]].
2. Вкажіть файл `.txt`.
3. Виберіть гру, до якої він належить.
4. У вікні видно цільовий Build ID. Якщо файл названо за іншим Build ID (або взагалі не за Build ID), його буде перейменовано на цільовий. Підтвердіть кнопкою **Import**.

Якщо в гри вже є файл читів для цього Build ID, його буде замінено.

## Переглянути встановлені чити
1. Виберіть [[View Cheats]]. У списку — усі встановлені ігри з читами, з title ID і кількістю файлів читів.
2. Натисніть **A** на грі. З'являться її файли читів за Build ID.
3. Натисніть **A** на файлі. З'являться чити з нього.
4. Натисніть **A** ([[View Code]]), щоб побачити код чита.

## Виправити чити після оновлення гри
Після оновлення гри старий файл читів має старий Build ID і не завантажується.

1. [[View Cheats]] → гра → наведіть на файл читів.
2. Натисніть **Y** ([[Fix BID]]).
3. У вікні видно старий і новий Build ID. Підтвердіть.

Файл перейменовується на поточний Build ID. Коди всередині не змінюються: чити для старішої версії після оновлення можуть не працювати або працювати неправильно.

## Видалити чити
- Один файл: [[View Cheats]] → гра → наведіть на файл → **X** ([[Delete]]).
- Одна гра: [[View Cheats]] → наведіть на гру → **Y** ([[Delete]]).
- Усі встановлені ігри: [[Delete All Cheats]]. Видаляє папки читів кожної гри, встановленої на консолі.
- Ігри, яких більше немає: [[Delete Orphaned]]. Видаляє чити невстановлених ігор.

## Очистити кеш завантажень
[[Clear Cheats Cache]] видаляє базу читів, яку Kefir Hub зберігає для [[Download Exact Cheats]] (`/config/hats-tools/cheats-db`). Під час наступного завантаження її буде отримано знову. Встановлених читів це не стосується.

## Файли
| Що | Шлях на карті пам'яті |
|---|---|
| Файли читів | `/atmosphere/contents/<title id>/cheats/<BUILD ID>.txt` |
| Кеш завантажень | `/config/hats-tools/cheats-db` |
| Завантажений набір (тимчасово) | `/config/kefir-updater/cheats.zip` |

## Параметри
У списку ігор [[Download Exact Cheats]] та [[Import From File]] натисніть **+**, щоб відкрити [[Cheats Options]]:

| Параметр | Що робить | Типово |
|---|---|---|
| [[Layout]] | [[Icon]], [[Grid]] або [[HB Menu]]. | [[Icon]] |

Там же **X** ([[Refresh]]) заново сканує ігри.

## Проблеми
**[[Cheats Not Found]].** У базі немає читів для цієї гри або для її Build ID (версії гри).

**Чити в грі не діють.** Build ID файлу не збігається з встановленою версією. Скористайтеся [Fix BID](#fix-cheats-after-a-game-update) або завантажте чити знову.

**Вікно повідомляє, що не вдалося визначити Build ID.** Запустіть гру один раз, закрийте її й спробуйте знову.

**[[No installed cheats found]].** У жодної встановленої гри немає файлу читів.

**[[Failed to install cheats pack]].** Перевірте з'єднання з інтернетом і вільне місце на карті пам'яті, потім спробуйте ще раз.
