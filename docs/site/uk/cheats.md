# [[Cheats]]

Завантаження чіт-кодів для ігор, імпорт власних файлів чітів, перегляд встановленого й видалення. Atmosphère завантажує чіти з карти пам'яті під час запуску гри.

**Де:** [[Tools]] → [[Game Tools]] → [[Cheats]]

<!-- shot: cheats-menu | Cheats menu with all eight entries, Download Kefir Cheats focused -->

## Як працюють чіти
Чіти кожної гри — це текстовий файл, названий за **Build ID** гри (код, що змінюється з кожним оновленням гри):

`/atmosphere/contents/<title id>/cheats/<BUILD ID>.txt`

Файл чітів працює лише для тієї версії гри, під яку його зроблено. Після оновлення гри старий файл уже не підходить — див. [Виправити чіти після оновлення гри](#fix-cheats-after-a-game-update).

Kefir Hub встановлює, показує й видаляє файли чітів. Вмикати чи вимикати окремі чіти він не вміє — це робиться в самій грі через оверлей EdiZon у меню Tesla. У Kefir меню Tesla відкривається комбінацією **L** + **R3** + **D-pad** вниз.

## Встановити повний набір чітів
1. Виберіть [[Download Kefir Cheats]] (чіти для багатьох ігор) або [[Download 60FPS/GFX Cheats]] (чіти на частоту кадрів, роздільність і графіку).
2. Підтвердіть кнопкою [[Download]].
3. Дочекайтеся повідомлення [[Cheats pack installed]].

Набір береться з проєкту switch-cheats-db і розпаковується в `/atmosphere`. Наявні файли чітів з такими самими назвами перезаписуються. Потрібне з'єднання з інтернетом.

Для пункту [[Download 60FPS/GFX Cheats]] є особливість: він більше не встановлює весь набір одразу. Після завантаження знизу відкривається список лише встановлених ігор, для яких у наборі є чіти, з позначкою біля кожної. Натискання пункту [[Install for ticked games]] додає чіти лише позначеним іграм. Під кожною грою вказується статус: [[For the installed version.]], [[Only for other versions of the game; may not work.]] або [[The installed version could not be checked.]]. Нові чіти з набору додаються до файлу чітів гри за назвою: наявні чіти з такою самою назвою лишаються як є, інші ігри не змінюються, а файл і далі проходить ліміти dmnt. Якщо для жодної встановленої гри немає чітів у наборі, з'являється повідомлення [[No installed game has cheats in this pack]]. 

Пункт [[Download Kefir Cheats]] працює як і раніше: розпаковує весь набір і перезаписує файли з такими самими назвами.

## Завантажити чіти для однієї гри
1. Виберіть [[Download Exact Cheats]].
2. Відкриється список встановлених ігор. Наведіть на гру й натисніть **A**.
3. Kefir Hub визначить Build ID гри й завантажить відповідні чіти. Build ID видно вгорі поруч із назвою гри.
4. Виберіть чіти:
    - **A** — [[Toggle]] (позначити чіт під курсором);
    - **X** — [[Select All]] (ще раз — зняти всі позначки);
    - **R** — [[Preview]] (переглянути код).
5. Натисніть **Y** ([[Download]]) і підтвердьте.

<!-- shot: cheats-select | Cheat list for one game: game name and Build ID at the top, three cheats ticked [X] -->

Нові чіти додаються до наявного файлу чітів гри; чіти з такою самою назвою пропускаються. Один файл може містити щонайбільше 127 чітів та один майстер-код; якщо порушено хоча б одне правило, Atmosphère не читає весь файл, тому Kefir Hub записує лише те, що приймає: другий майстер-код, чіти довші за 256 кодових слів і чіти після 127-го пропускаються, а повідомлення вказує їхню кількість («Atmosphere limits: skipped N cheat(s)»). Весь файл перевіряється заново щоразу, коли додаються чіти, а також ті чіти, що вже були в ньому; ручний імпорт використовує ту саму перевірку. Коли гра була запущена або не знайдено prod.keys, Kefir Hub зчитував Build ID із перевернутими байтами, через що файл отримував неправильну назву й Atmosphère його не завантажувала; файли, створені таким чином, можна перейменувати за допомогою **Y** ([[Fix BID]]) у списку файлів чітів гри.

!!! tip
    Запустіть гру один раз, закрийте її, а тоді завантажуйте. Найнадійніше Kefir Hub визначає Build ID із запущеної або встановленої гри. Якщо не вдається, він шукає версію онлайн, а це для деяких ігор може дати хибний результат.

Kefir вивантажує ключі консолі (prod.keys) під час завантаження, тому це трапляється рідко; коли Kefir Hub потрібні вони для зчитування Build ID і відсутній файл `/switch/prod.keys`, він повідомляє про це та пропонує вивантажити їх зараз за допомогою Lockpick_RCM (консоль перезавантажується в пейлоад); якщо Lockpick_RCM немає в `/bootloader/payloads`, у повідомленні зазначено покласти його туди. Ця пропозиція з'являється також для ручного імпорту та [[Fix BID]].

## Імпортувати файл чітів
Для файлу `.txt` з чітами, який ви скопіювали на карту пам'яті.

1. Виберіть [[Import From File]].
2. Вкажіть файл `.txt`.
3. Виберіть гру, до якої він належить.
4. У вікні видно цільовий Build ID. Якщо файл названо за іншим Build ID (або взагалі не за Build ID), його буде перейменовано на цільовий. Підтвердіть кнопкою **Import**.

Якщо в гри вже є файл чітів для цього Build ID, його буде замінено.

## Переглянути встановлені чіти
1. Виберіть [[View Cheats]]. У списку — усі встановлені ігри з чітами, з title ID і кількістю файлів чітів.
2. Натисніть **A** на грі. З'являться її файли чітів за Build ID.
3. Натисніть **A** на файлі. З'являться чіти з нього.
4. Натисніть **A** ([[View Code]]), щоб побачити код чита.

## Виправити чіти після оновлення гри
Після оновлення гри старий файл чітів має старий Build ID і не завантажується.

1. [[View Cheats]] → гра → наведіть на файл чітів.
2. Натисніть **Y** ([[Fix BID]]).
3. У вікні видно старий і новий Build ID. Підтвердіть.

Файл перейменовується на поточний Build ID. Коди всередині не змінюються: чіти для старішої версії після оновлення можуть не працювати або працювати неправильно.

## Видалити чіти
- Один файл: [[View Cheats]] → гра → наведіть на файл → **X** ([[Delete]]).
- Одна гра: [[View Cheats]] → наведіть на гру → **Y** ([[Delete]]).
- Усі встановлені ігри: [[Delete All Cheats]]. Видаляє папки чітів кожної гри, встановленої на консолі.
- Ігри, яких більше немає: [[Delete Orphaned]]. Видаляє чіти невстановлених ігор.

## Очистити кеш завантажень
[[Clear Cheats Cache]] видаляє базу чітів, яку Kefir Hub зберігає для [[Download Exact Cheats]] (`/config/hats-tools/cheats-db`). Під час наступного завантаження її буде отримано знову. Встановлених чітів це не стосується.

## Файли
| Що | Шлях на карті пам'яті |
|---|---|
| Файли чітів | `/atmosphere/contents/<title id>/cheats/<BUILD ID>.txt` |
| Кеш завантажень | `/config/hats-tools/cheats-db` |
| Завантажений набір (тимчасово) | `/config/kefir-updater/cheats.zip` |

## Параметри
У списку ігор [[Download Exact Cheats]] та [[Import From File]] натисніть **+**, щоб відкрити [[Cheats Options]]:

| Параметр | Що робить | Типово |
|---|---|---|
| [[Layout]] | [[Icon]], [[Grid]] або [[HB Menu]]. | [[Icon]] |
| [[Match Build ID exactly]] | Якщо вимкнути і в базі немає чітів для Build ID вашої гри, Kefir Hub бере чіти найближчої версії гри з бази й зберігає їх під Build ID вашої гри; про це показується повідомлення. Коди можуть не працювати, бо створені для іншої версії. | Увімк. |

Там же **X** ([[Refresh]]) заново сканує ігри.

## Проблеми
**[[Cheats Not Found]].** У базі немає чітів для цієї гри або для її Build ID (версії гри).

**Чіти в грі не діють.** Build ID файлу не збігається з встановленою версією. Скористайтеся [Fix BID](#fix-cheats-after-a-game-update) або завантажте чіти знову.

**Вікно повідомляє, що не вдалося визначити Build ID.** Запустіть гру один раз, закрийте її й спробуйте знову.

**[[No installed cheats found]].** У жодної встановленої гри немає файлу чітів.

**[[Failed to install cheats pack]].** Перевірте з'єднання з інтернетом і вільне місце на карті пам'яті, потім спробуйте ще раз.
