# Встановлення ігор

Kefir Hub встановлює ігри, оновлення та DLC з файлів-пакетів. Ця сторінка допоможе вибрати спосіб і пояснює налаштування, спільні для всіх способів.

!!! warning
    За встановлення ігор, які ви не купували, консоль можуть заблокувати в онлайн-сервісах Nintendo.

## Попередження про бан на sysMMC {#ban-warning}

Встановлення завжди дозволене. Перемикача, що його вмикає, немає.

На emuMMC Kefir Hub не показує попередження перед встановленням. На sysMMC він показує попередження про бан перед початком встановлення: що бачить Nintendo, які онлайн-сервіси можуть заблокувати, і що emuMMC безпечніший. У ньому три кнопки:

- [[Back]] скасовує встановлення.
- [[Install]] починає встановлення; наступного разу попередження зʼявиться знову.
- [[Don't show again]] вимикає попередження і починає встановлення.

Попередження зʼявляється перед кожним встановленням з таких джерел: файловий менеджер (Install, Install recursively, **A** на файлі NSP або XCI), Install Forwarder у файловому менеджері та в Homebrew, Ownfoil, Console Transfer (отримання ігор) і PC Install (USB). Встановлення через MTP і мережеві потоки (FTP, веб-сервер) попередження не показують.

Щоб увімкнути попередження знову: [[Tools]] → [[Settings]] → [[Install]] → [[Ban warning on sysMMC]]. Цей самий параметр є в бічному меню: Menu (**Y**) → Advanced → Install options. Ключ в ini: `install_ban_warning`. Типово: увімкнено.

<!-- shot: install-index-ban-warning | Ban warning dialog on sysMMC with Back, Install and Don't show again buttons -->

Після встановлення гри Kefir Hub лишає власну іконку HOME Menu першою, якщо його запущено з цієї іконки. Раніше кожне встановлення переносило її в кінець списку.

## Виберіть спосіб {#methods}

| Спосіб | Що потрібно | Перегляд перед встановленням | Сторінка |
|---|---|---|---|
| З карти пам'яті або USB-накопичувача | Файли на карті чи накопичувачі | Так | [Встановлення з карти пам'яті](sd-card.md) |
| З ПК через USB | USB-кабель і програма на ПК (DBI Backend, ns-usbloader, Fluffy) | Так | [Встановлення з ПК через USB](usb.md) |
| З ПК через MTP | USB-кабель і файловий менеджер ПК | Ні, гра встановлюється під час копіювання | [Встановлення через MTP](mtp.md) |
| Через мережу | Wi-Fi; FTP-клієнт, браузер або сервер Ownfoil | Залежить від способу | [Встановлення через мережу](network.md) |
| З картриджа | Картридж у слоті | — | [Картриджі](gamecard.md) |

Способи з карти пам'яті та через USB відкривають ту саму чергу встановлення: спершу кожен пакет перевіряється, ви бачите, скільки місця він потребує і куди піде, а тоді вибираєте, що встановити. MTP встановлює кожен файл, щойно ПК починає його копіювати, тож файл на консолі не зберігається.

## Підтримувані файли {#formats}

- **NSP** і **NSZ** (NSZ — стиснений NSP).
- **XCI** і **XCZ** (XCZ — стиснений XCI).

Стиснені файли розпаковуються під час встановлення, тому потребують більше пам'яті. У режимі аплету пам'яті мало, і пакети NSZ навряд чи встановляться. Запускайте Kefir Hub у режимі тайтлу: утримуйте **R**, запускаючи встановлену гру, доки не відкриється hbmenu, або скористайтеся іконкою Kefir Hub у HOME-меню (див. [Початок роботи](../getting-started.md)).

## Куди встановлюються ігри {#location}

Кожен пакет потрапляє або на карту пам'яті, або в пам'ять системи (NAND). Куди саме — визначає [[Install location]]:

| Значення | Що робить |
|---|---|
| [[microSD card only]] | Завжди на карту пам'яті. |
| [[System memory only]] | Завжди в пам'ять системи. |
| [[System first, then SD]] | У пам'ять системи, доки вона не заповниться, далі на карту пам'яті. |
| [[SD first, then system]] | На карту пам'яті, доки вона не заповниться, далі в пам'ять системи. |
| [[Automatic]] | Туди, де після встановлення вільне місце на обох сховищах буде найрівнішим. Якщо пакет вміщається лише на одне — туди. Типове значення. |

Плануючи, куди піде пакет, Kefir Hub залишає вільними 500 МБ на кожному сховищі. Змінити це можна в [[Options]] черги: [[Reserve free space (system)]] і [[Reserve free space (microSD)]] (див. [Параметри черги](sd-card.md#queue-options)). Якщо вибрані пакети з урахуванням резерву не вміщаються, черга запитає [[Selected packages may not fit after the configured reserve. Continue?]].

У черзі встановлення можна задати сховище й для окремого пакета: виділіть його й натисніть **L3** ([[Package target]]), щоб перемикати [[Auto]], [[microSD]] і [[System memory]].

| [[Re-encrypt to master key 0]] | Перешифровує ключі гри, щоб їх могла прочитати будь-яка прошивка. Гра все одно може не працювати; краще оновити прошивку. Потрібні ключі консолі. | Вимк. |
| [[Lower required firmware]] | Знижує версію прошивки, яку вимагає гра. Не допоможе, якщо грі потрібні ключі, яких ваша прошивка не має. | Вимк. |

У меню [[Options]] черги (натисніть **+** у черзі) є [[Skip if already installed]], [[Install location]] і налаштування резерву, тож їх можна змінити для одного сеансу. Див. [Параметри черги](sd-card.md#queue-options).

Встановлення через MTP, FTP і браузер не використовують [[Skip if already installed]], [[Convert to standard crypto]] і [[Re-encrypt to master key 0]]: вміст завжди встановлюється заново, а гра не конвертується.

### Відновити тікети {#repair-tickets}
Під час встановлення з карти пам'яті, USB-накопичувача або з ПК через USB параметр [[Skip if already installed]]
у значенні [[Skip]] пропускає весь пакет уже встановленої гри разом із тікетом. Тому сам лише
[[Install tickets only]] для встановленої гри нічого не робить.

1. Увімкніть [[Install tickets only]].
2. Для [[Skip if already installed]] виберіть [[Reinstall]].
3. Встановіть пакет гри ще раз.

Встановлення через MTP, FTP і браузер завжди імпортують тікети.

## Проблеми {#problems}

Коли всі записи вмісту пакета успішно зареєстровано, Kefir Hub на HOS 6.0.0 і новіших сам скидає в нуль локальну потрібну версію запуску базової гри для кожного встановленого оновлення. Параметр чи ручні дії не потрібні.

- Це працює для звичайних і потокових встановлень. Пропущені оновлення в чергу не потрапляють. Якщо пізніший запис вмісту завершився помилкою або його скасовано, уже зареєстровані оновлення отримують скидання за можливості, а початкова помилка встановлення лишається видимою.
- Версії пакетів не змінюються. Це не блокує пізніші онлайн-перевірки версії Nintendo і не знімає вимог від DLC, збережень чи прошивки.
- Збій скидання показується як помилка встановлення. Уже зареєстрований вміст лишається встановленим. Прочитані значення й помилки читання записуються в журнал для перевірки на консолі.

Після встановлення будь-яким способом (через файловий менеджер, ПК, MTP, FTP або браузер), якщо залишається оновлення або DLC без основної гри, Kefir Hub приблизно через п'ять секунд після останнього файлу показує одне вікно зі списком таких назв із написом «Installed without the base game». Параметр [[Keep]] (типово) залишає їх, а [[Delete]] видаляє їх (збереження залишаються). Залишайте їх, якщо основна гра на картриджі, або встановіть основну гру згодом. Це вікно також з'являється для черги DBI/PC.

**Гру встановлено, але консоль каже, що запустити її поки не можна.** Грі потрібна новіша системна прошивка, ніж на консолі. Оновіть прошивку й Kefir (див. [Оновлення](../updater.md)). Перевстановлювати гру не потрібно.

**Пакет пропущено, бо його вже встановлено.** [[Skip if already installed]] має значення [[Skip]]. Виберіть [[Reinstall]] або [[Prompt]].

**Оновлення пропущено.** Воно старіше за встановлене. Увімкніть [[Allow downgrade]], якщо хочете повернутися до нього.

**Файли NSZ не встановлюються в режимі аплету.** Запустіть Kefir Hub у режимі тайтлу.

**Потрібні подробиці помилок.** Помилки встановлення записуються в `/config/kefir/errors.txt` на карті пам'яті, навіть коли журнал вимкнено.
