# Встановлення через мережу

Встановлюйте ігри, оновлення та DLC без кабелю: з браузера на ПК чи телефоні, з FTP-програми, з власного
сервера Ownfoil або з мережевої папки. Консоль і другий пристрій мають бути в одній мережі.

| Спосіб | Що потрібно | Показує відсотки й час, що лишився | Розділ |
|---|---|---|---|
| Браузер | Будь-який браузер на ПК чи телефоні | Так | [Встановлення з браузера](#browser) |
| FTP | FTP-програма на ПК (наприклад, FileZilla чи WinSCP) | Ні | [Встановлення через FTP](#ftp) |
| Ownfoil | Сервер Ownfoil на вашому ПК чи NAS | Так | [Встановлення із сервера Ownfoil](#ownfoil) |
| Мережева папка | Сервер SMB, NFS, WebDAV, FTP або HTTP | Так | [Встановлення з мережевої папки](#network-share) |

## Перед початком {#before}

- Увімкніть встановлення. Див. [Увімкнути встановлення](index.md#enable).
- Підключіть консоль до Wi-Fi або LAN-адаптера. Угорі екрана видно назву мережі та IP-адресу консолі, наприклад
  `MyWiFi · 192.168.1.5`. Без підключення там написано [[No Internet]].
- Обидва пристрої мають бути в одній мережі. Гостьова Wi-Fi зазвичай ізолює пристрої, і ПК не бачить консолі.
- За можливості запускайте Kefir Hub у режимі Title Mode. У режимі Applet Mode пам'яті мало, і файли NSZ навряд
  чи встановляться (див. [Підтримувані файли](index.md#formats)).
- Куди піде кожна гра (на карту пам'яті чи в системну пам'ять), визначає [[Install location]]. Див.
  [Куди встановлюються ігри](index.md#location).

## Встановлення з браузера {#browser}

Kefir Hub запускає невеликий вебсервер. Ви відкриваєте його сторінку в браузері й завантажуєте туди файли ігор.

**Де:** [[Tools]] → **+** → [[Install & Share]] → [[Web Server]]

<!-- shot: network-install-share-panel | Tools screen with the Install & Share panel open on the right, Web Server highlighted -->

1. Відкрийте [[Tools]] і натисніть **+**. Відкриється панель [[Install & Share]].
2. Виберіть [[Web Server]].
   У режимі Applet Mode спершу відкриється панель [[Web Server — Applet Mode]]. Виберіть [[Start anyway]] або
   [[Install Title Mode forwarder]], щоб додати значок Kefir Hub на HOME Menu і наступного разу запускати Kefir Hub
   з нього. Пункт [[How to enter Title Mode]] показує інший спосіб запуску в Title Mode.
3. Відкриється вікно [[Web Sharing Server]] з QR-кодом і адресою, наприклад `http://kefir.local` або
   `http://192.168.1.5:8080`.
4. Відскануйте QR-код телефоном або введіть адресу в браузері на ПК.
5. Відкриється сторінка **Kefir Hub Files**. Перейдіть у папку, куди мають потрапити інші файли. Для файлів ігор
   папка не важлива.
6. Натисніть **Add to Upload** і виберіть файли.
7. Натисніть **Queue**. Панель черги покаже файли. У файлів ігор (`.nsp`, `.nsz`, `.xci`, `.xcz`) позначено
   **Install directly**.
8. Натисніть **Start transfers**.
9. Консоль покаже екран встановлення [[Web install]] з кількістю пакетів, відсотком і часом, що лишився.
   Коли гру встановлено, з'явиться [[Web install success!]], а у вікні сервера — [[Installation completed]].
10. Коли закінчите, натисніть **B** у вікні сервера, щоб зупинити його.

<!-- shot: network-web-server-qr | Web Sharing Server window with the QR code, the address and "Press B to Stop Server" -->
<!-- shot: network-web-queue | Browser: Kefir Hub Files page with the Queue panel open, two NSP files with "Install directly" ticked -->

Що відбувається з кожним файлом:

| Файл | Що робить Kefir Hub |
|---|---|
| `.nsp`, `.nsz`, `.xci`, `.xcz` з позначкою **Install directly** | Встановлює його під час завантаження. На карті пам'яті файл не зберігається. |
| `.nsp`, `.nsz`, `.xci`, `.xcz` без позначки **Install directly** | Зберігає його в папку, відкриту в браузері. |
| `.nro` (homebrew) | Зберігає його як `/switch/<назва>/<назва>.nro`, замінюючи старішу копію. Він з'явиться на вкладці [[Homebrew]]. |
| Будь-який інший файл | Зберігає його в папку, відкриту в браузері. Якщо файл із такою назвою вже є, новий отримає номер: `name (1).ext`. |

!!! tip
    Натисніть **L3**, щоб згорнути вікно сервера до значка в куті й далі користуватися Kefir Hub. Ще раз **L3**
    повертає вікно. У режимі Applet Mode тримайте вікно відкритим: там сервер має менше пам'яті.

Сервер зупиняється сам, коли консоль втрачає мережу ([[Web server stopped: the console went offline]]) або отримує
нову IP-адресу ([[Web server stopped: the console's IP address changed]]). Запустіть його знову; адреса може
змінитися.

На вебсторінці також можна завантажувати на ПК, видаляти й переглядати файли. Див.
[Доступ до файлів з ПК](../sharing.md#web).

## Встановлення через FTP {#ftp}

Копіюйте файли ігор на консоль FTP-програмою. Кожен файл встановлюється під час копіювання й не зберігається на
карті пам'яті.

**Де:** [[Tools]] → [[Settings]] → [[Network]] → [[FTP]]

1. Увімкніть [[FTP]]. Тепер FTP-сервер працює у фоні, поки відкрито Kefir Hub, і запускається разом із Kefir Hub,
   доки ви його не вимкнете.
2. Запам'ятайте IP-адресу консолі вгорі екрана.
3. У FTP-програмі підключіться до цієї адреси на порт `5000`. З типовими налаштуваннями підходить будь-яке ім'я
   користувача й пароль. Щоб це змінити, див. [Налаштування FTP](../sharing.md#ftp-settings).
4. Відкрийте на сервері папку `install`.
5. Скопіюйте в неї файли `.nsp`, `.nsz`, `.xci` або `.xcz`. Можна копіювати кілька одразу; вони встановлюються
   по черзі.
6. Консоль покаже екран встановлення [[FTP Install]]. Після кожного файлу з'явиться [[FTP install success!]].

<!-- shot: network-ftp-client | FTP program connected to the console, the server's top level with the install folder -->
<!-- shot: network-ftp-progress | FTP Install screen: Mode FTP, Installed, Written, Average speed, no percent -->

Файл `.nro`, скопійований у `install`, не встановлюється як гра: він зберігається як `/switch/<назва>/<назва>.nro`
і з'являється на вкладці [[Homebrew]].

!!! warning
    Файл гри, скопійований на верхній рівень сервера, теж встановлюється, а не зберігається.
    <!-- TODO(verify): code (ftp_root_write_router) also routes a game file dropped into the top of the microSD card folder (sdmc:/) to the installer. Confirm on hardware; if so, say "the top level of the server or of the microSD card". -->
    Щоб зберегти файл гри на карті пам'яті, скопіюйте його в підпапку.

### Що показує прогрес {#ftp-progress}

FTP-програма не повідомляє консолі розмір файлу. Тому на екрані [[FTP Install]] немає відсотків і часу, що лишився.
Там видно:

- [[Mode]]: `FTP`.
- [[Installed]]: скільки файлів уже готово.
- [[Written]]: скільки даних уже записано.
- [[Average speed]].

Згорнутий кнопкою **L3** значок показує `--` замість відсотка. Коли FTP-програмі більше нічого надсилати, екран
змінюється на [[Session summary]] (див. [Коли черга завершилася](sd-card.md#summary)).

Щоб скасувати, зупиніть передавання у FTP-програмі. Консоль покаже
[[Install cancelled: the source stopped sending data]].

## Встановлення із сервера Ownfoil {#ownfoil}

Ownfoil — це сервер бібліотеки ігор, який ви запускаєте на власному ПК чи NAS. Kefir Hub показує його каталог і
встановлює звідти.

**Де:** [[Tools]] → **+** → [[Install & Share]] → [[Ownfoil]] або [[Tools]] → [[Software]] → [[Ownfoil]]

<!-- shot: network-ownfoil-servers | Ownfoil server list: one saved server with its local address, one found server tagged New, Discover local servers button -->

### Додати сервер {#ownfoil-add}

Знайти в мережі:

1. Виділіть [[Discover local servers]] і натисніть **A**. Кнопка ненадовго покаже [[Searching the network...]].
2. Знайдені, але ще не збережені сервери позначено [[New]]. Виберіть потрібний.
3. Kefir Hub повідомить, чи потрібен магазину вхід: [[This shop is public. Set up a login anyway?]] або
   [[This shop is private. Set up a login now?]]. [[Yes]] відкриває форму сервера, [[No]] зберігає сервер без
   входу й підключається.

Або додайте вручну: натисніть **X** ([[Options]]) і виберіть [[Add server]]. Заповніть форму [[Ownfoil Server]] і
виберіть [[Save]].

| Поле | Що ввести |
|---|---|
| [[Name]] | Будь-яку назву. Після першого підключення її замінить назва, яку повідомить сервер. |
| [[Local address]] | Адресу в домашній мережі, наприклад `192.168.1.10:8465`. |
| [[Remote address]] | Адресу з інтернету, наприклад `shop.example.com`. Назву без `http://` буде відкрито через `https://`. |
| [[User]], [[Pass]] | Необов'язковий вхід у магазин. |

Потрібні назва й хоча б одна адреса. Kefir Hub спершу пробує локальну адресу, потім віддалену.

Щоб змінити чи видалити збережений сервер, виділіть його, натисніть **X** і виберіть [[Edit server]] або
[[Delete server]].

### Встановити гру {#ownfoil-install}

1. Виберіть сервер і натисніть **A**. **B** зупиняє підключення.
2. Каталог відкривається на [[New games]]. Натисніть **Y** ([[Show]]), щоб вибрати, що показати:

    | Пункт | Що показує |
    |---|---|
    | [[New games]] | Ігри із сервера, яких немає на цій консолі. |
    | [[Updates]] | Оновлення для ігор на цій консолі. |
    | [[DLC]] | DLC для ігор на цій консолі. |
    | [[All games]] | Увесь каталог. |
    | [[Search]] | Питає назву або ID гри й показує збіги. |

3. **ZL** / **ZR** гортають сторінки, **−** змінює вигляд.
4. Виберіть гру. На її сторінці є опис і знімки екрана; **Y** ([[Full screen]]) відкриває знімки.
5. Натисніть **A** ([[Install]]). Відкриється панель:
    - [[Install options]]: налаштування встановлення (див. [Параметри встановлення](index.md#install-options)).
    - [[Version]]: яку версію встановити.
    - [[Add-on content]]: позначте DLC, які встановити разом із грою.
    - Останній пункт запускає встановлення. Він називається [[Install]], [[Update]] або [[Downgrade]] залежно від
      вибраної версії. Він сірий, якщо встановлювати нічого.
6. Вікно прогресу показує завантаження й встановлення.

<!-- shot: network-ownfoil-catalog | Ownfoil catalog in Icon view, New games selected, page counter visible -->
<!-- shot: network-ownfoil-install-panel | Install panel of a game: Install options, Version, Add-on content, Install -->

### Параметри каталогу {#ownfoil-options}

Натисніть **X** ([[Options]]) у каталозі.

| Параметр | Що робить | Типово |
|---|---|---|
| [[View]] | [[Icon]], [[Banner]] або [[Detail]]. **−** теж перемикає їх. | [[Icon]] |
| [[Per page]] | Скільки ігор на одній сторінці. | 24 |
| [[Sort]] | За назвою, датою додавання або датою виходу. | За назвою |
| [[Order]] | [[Ascending]] або [[Descending]]. | [[Ascending]] |
| [[Servers list]] | Повернутися до списку серверів. | |
| [[Clear cache]] | Видаляє збережені обкладинки ігор з карти пам'яті. | |

## Встановлення з мережевої папки {#network-share}

Kefir Hub може відкривати папки на сервері SMB, NFS, WebDAV, FTP або HTTP і встановлювати з них так само, як із
карти пам'яті.

1. Відкрийте [[Tools]] → [[Settings]] → [[Sources]] → [[+ Add network location]] і налаштуйте сервер.
   Див. [Налаштування](../settings.md#sources).
2. Виберіть це розташування. Воно відкриється у [Файловому менеджері](../file-browser.md).
3. Виберіть файли ігор, натисніть **+** і виберіть [[Install]] (або [[Install recursively]] для цілої папки).
4. Відкриється черга встановлення. Далі — як у розділі [Перегляньте чергу](sd-card.md#queue).

## Проблеми {#problems}

**Пункт [[Web Server]] сірий.** Консоль не підключено до мережі. Натисніть його все одно: Kefir Hub повідомить
[[The console has no internet connection.]] і запропонує підключитися.

**Браузер не відкриває `kefir.local`.** Деякі телефони й ПК не знаходять адрес `.local`. Введіть замість неї
IP-адресу, яку видно вгорі екрана консолі, з портом, якщо він був в адресі (`http://192.168.1.5:8080`).

**Сторінка не відкривається взагалі.** Перевірте, що обидва пристрої в одній мережі і це не гостьова Wi-Fi.
Якщо Kefir Hub показав [[Web listener started, but its local self-test failed; check the log or use Title Mode]],
запустіть Kefir Hub у режимі Title Mode і спробуйте ще раз.

**У черзі написано «Error: Another transfer is already in progress».** Одночасно працює лише одне завантаження чи
встановлення. Дочекайтеся, поки попереднє завершиться.

**[[Install failed: another installation is in progress.]]** Вже триває інше встановлення (USB, MTP, FTP чи з
браузера). Дочекайтеся його завершення.

**[[Install cancelled: the source stopped sending data]]** Браузер чи FTP-програма перестали надсилати дані,
наприклад ПК заснув або обірвалося з'єднання. Почніть копіювання знову.

**FTP-програма не підключається.** Перевірте, що [[FTP]] увімкнено і ви використовуєте порт `5000` (або той, що в
[Налаштуваннях FTP](../sharing.md#ftp-settings)). Якщо вхід відхилено, див.
[Налаштування FTP](../sharing.md#ftp-settings).

**Файл гри, скопійований через FTP, не встановився.** Його скопійовано в підпапку, тож він зберігся як звичайний
файл. Скопіюйте його в `install`.

**Файли NSZ не встановлюються.** Запустіть Kefir Hub у режимі Title Mode (див. [Підтримувані файли](index.md#formats)).

**Ownfoil показує [[Network access required]].** Консоль не підключено до мережі.

**Ownfoil пише [[This account has no shop access]].** Користувач у формі сервера не має доступу до магазину.
Змініть [[User]] і [[Pass]] через [[Edit server]].

**[[Discover local servers]] нічого не знаходить.** Додайте сервер вручну за IP-адресою й портом.
