# Картриджі

Що Kefir Hub робить із картриджем, вставленим у слот консолі.

**Де:** [[Tools]] → [[Game Tools]] → [[Games]]

У цій версії немає окремого меню картриджа: встановити вміст картриджа на консоль із Kefir Hub не можна.

## Знайдіть картридж {#find}

1. Вставте картридж.
2. Відкрийте [[Tools]] → [[Game Tools]] → [[Games]].
3. Картридж — угорі списку. Його іконка обведена рамкою й має позначку GC.

<!-- shot: install-gamecard-games-row | Games list with the game card row at the top, GC badge and outline -->

## Збережіть картридж у файли NSP {#dump}

1. Виділіть картридж у [[Games]] і натисніть **+**.
2. Виберіть [[Dump]] і що саме зберегти, наприклад [[Dump All]].
3. Виберіть, куди зберегти файли.

Збереження ігор у файли описано на сторінці [Ігри](../games.md). Налаштування — у [[Games]] → **+** → [[Advanced options]] → [[Dump options]].
