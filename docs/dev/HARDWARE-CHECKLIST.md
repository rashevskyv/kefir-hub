# Апаратний чекліст (Switch + ПК)

Виконує користувач. Заповнюється після кожного build checkpoint, що зачіпає MTP/USB/saves.
Формат рядка: `- [ ] A1 … — v0.13.XXX: PASS | FAIL (що саме сталося)`. Baseline: версія з задачі 1.1.
Ці сценарії не перевірялися з v0.13.903 по v0.13.922 (20 версій) — тому спершу baseline, потім зміни.

## A. MTP — передача та скасування (історія v0.13.903–922)
- [ ] A1 Копіювання 1 NSP на «Install» з ПК → встановлення стартує, плашка прогресу з'являється і закривається після завершення, не зависає на останньому файлі.
- [ ] A2 Копіювання папки з 3+ файлами на microSD → усі файли на місці, плашка оновлює ім'я файла, закривається один раз у кінці.
- [ ] A3 Скасування на Switch (B у ProgressBox) під час передачі → передача припиняється ≤ 2 с, неповний файл видалено, MTP лишається видимим на ПК **без** перепідключення кабелю, USB не переходить у host mode.
- [ ] A4 Скасування на ПК (Cancel у провіднику Windows) під час передачі → Switch не зависає, плашка закривається, наступна передача працює без перепідключення.
- [ ] A5 Відключення кабелю під час передачі → додаток не падає; після підключення MTP знову працює.
- [ ] A6 Скасування під час установки NSP (modal підтвердження доступне) → установка зупинена, сесія звільнена, наступний NSP встановлюється.
- [ ] A7 Подвійне скасування (B двічі швидко) → без краху, один лог cancel.
- [ ] A8 Скасування в «idle window» (одразу після завершення файла, до початку наступного) → плашка не з'являється повторно, нічого не зависає.
- [ ] A9 Маршрутизація: NSP/NSZ/XCI/XCZ у корінь «Nintendo Switch» → потрапляє в Install; інші файли → microSD як фізичні файли.
- [ ] A10 Згорнута плашка (L3) під час MTP-установки показує правильний прогрес за розміром пакунка.
- [ ] A11 Вимкнення MTP у налаштуваннях під час передачі → коректна зупинка; увімкнення знову працює при підключеному VBUS.

## B. Збереження (saves)
- [ ] B1 Backup Account-сейву в ZIP → архів у вибраній папці (`/dumps` типово), metadata присутня.
- [ ] B2 Restore того ж ZIP → гра бачить сейв; без повторного запиту про створення слота.
- [ ] B3 Backups згруповано за походженням (Kefir Hub / DBI / JKSV / Checkpoint); папковий бекап JKSV відновлюється.
- [ ] B4 Restore для невстановленої гри → слот створено з archive-metadata, помилки немає.
- [ ] B5 «Відновити все» з 2+ архівами → посторінковий перегляд, відсутні архіви заблоковано до запису.
- [ ] B6 Навігація: UP з першого бекапа переходить на останній; «−» закриває файловий браузер, відкритий з меню.

## C. Інше з історії
- [ ] C1 Перший запуск після видалення `config` → діалог вибору мови (алфавітний список, без російської); вибір збережено; старий ID мови мігрує.
- [ ] C2 Форвардер поточного додатка з меню «+» → створено з 39-біт та 3 ядрами; варіант з 4 ядрами встановлюється після підтвердження.
- [ ] C3 USB-установка з DBI Backend (SPHQ): додати пакунок у чергу під час передачі → він з'являється; видалити → зникає; порожня черга — без зависання.
- [ ] C4 Веб-файл-менеджер: завантажити файл у корінь SD → файл на місці.
- [ ] C5 Вихід із додатка під час активної MTP-передачі → коректний вихід без краху (лог без panic).
