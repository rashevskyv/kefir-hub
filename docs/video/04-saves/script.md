# 04. Saves: backup, restore, DBI/JKSV/Checkpoint backups, WebDAV
**Length:** ~5 min · **Docs:** saves.md
**Before recording:**
- Console UI language: Ukrainian. Two user profiles on the console.
- Game A installed, with a save for user 1 (played at least once). Game B installed, with a save. All games closed.
- Three older Kefir Hub backups of game A in `/dumps` (make them before recording, a few minutes apart) for the Select backup list.
- A DBI backup ZIP of game B in `/switch/DBI/saves` (made with DBI), so the Backups tab shows a DBI group. Optional: a JKSV folder in `/JKSV`.
- MTP **off** (no USB cable connected; Settings → Network → MTP off).
- Wi-Fi connected. A WebDAV server on the PC or NAS, already added as a network location and chosen in Settings → Saves → Save sync location. Auto-sync after backup is On by default; turn it **off** before scene 4, or the first backup also uploads to WebDAV.
- Optional: one game deleted earlier whose save is still on the console (for the Deleted Games tab).
