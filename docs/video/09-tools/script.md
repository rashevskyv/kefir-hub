# 09. Tools: files, homebrew, App Store, modules, fan, Wi-Fi, Kefir Settings
**Length:** ~5 min · **Docs:** file-browser.md, homebrew.md, software.md, system-tools.md, kefir-settings.md

**Before recording:**
- UI language Ukrainian. Wi-Fi connected (App Store, translation list).
- Memory card: a few homebrew apps in `/switch`; a test folder with some files to copy and delete (for example `/video-test`); one small `.zip` archive; an `.ini` file with an `enabled = true` style line (a copy, not a live config); a FAT32 or exFAT USB drive connected for the two-pane shot (optional, otherwise both panes show the card).
- MTP turned off in Settings → Network (USB storage and MTP share the port).
- App Store: one app not installed (to install on camera) and one installed app with an update available, if possible.
- Module Manager: a few sysmodules installed, at least one running and one stopped. Pick a harmless module to toggle on camera (not sys-patch, not the fan module).
- Fan curve: the Kefir fan module not yet installed, so the install offer can be filmed. Restore the original curve after recording.
- Wi-Fi: two networks saved in System Settings, one of them connected. Do not open View password & details on camera with a real password.
- Kefir Settings: film the list and the hold-to-confirm box, then press B. Do **not** confirm any switch on camera except USB 3.0 with Later, and never 8GB DRAM status. Translate Interface: film the list only; installing a translation reboots and replaces a system language, so do it on a test console if you film it.
