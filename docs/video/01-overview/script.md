# 01. Kefir Hub overview
**Length:** ~5 min · **Docs:** index.md, getting-started.md
**Before recording:**
- Console UI language: Ukrainian (Kefir Hub language: Українська).
- Kefir Hub at `/switch/kefir-hub/kefir-hub.nro`. The Title Mode forwarder icon is **not** installed yet (scene 6 installs it).
- Replace hbmenu on exit is Off.
- At least one installed game (to start Kefir Hub with **R** held) and 5–10 homebrew apps on the card (Homebrew tab is not empty).
- Wi-Fi connected (name and IP visible in the header). FTP turned on in Settings → Network so the FTP badge shows a green dot.
- Console undocked, no USB cable connected.
- For scene 24: a screen that offers Manual (Keyboard) / From Phone / PC (e.g. Tools → Software → Custom Link).
- For scene 26: have a way back to Українська off camera after the restart (the scene switches to another language).
