# 05. Managing games: move, dump, delete, save slots
**Length:** ~4.5 min · **Docs:** games.md
**Before recording:**
- Console UI language: Ukrainian. Two user profiles.
- Game A: small, installed fully in system memory (NAND), base game + one update. Enough free space on the microSD card to move it.
- Game B: installed on the microSD card with base game, update and at least one DLC (for the Content tab and the component move).
- Game C: a small throwaway game with a save for user 1 (it gets deleted in scene 21; back up its save first if it matters).
- One installed game where user 2 has **no** save yet (for Create save slot).
- Free space on the microSD card at least the size of game A (for the dump to `/dumps/NSP/`).
- No game running.
