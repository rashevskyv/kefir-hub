# 08. Cheats and themes
**Length:** ~4 min · **Docs:** cheats.md, themes.md

**Before recording:**
- UI language Ukrainian. Wi-Fi connected (cheat packs, cheat database, Themezer and the theme packs are downloaded).
- Cheats are fine on any console, but film cheats in offline play only; a test console or emuMMC is preferred.
- Installed games: one game that has cheats in the database for its current version, started once and closed before recording (so the Build ID is read from the game).
- One game with a cheat file named after an older Build ID (installed before a game update), for Fix BID.
- A `.txt` cheat file copied to the memory card (for example in `/downloads`) for Import From File.
- At least one game without cheats installed, so View Cheats shows only games that have them after the pack.
- NXThemes Installer **not** on the card at the start, so the download prompt can be filmed (Kefir Hub downloads it on camera). After that it stays installed.
- A screenshot or other 1280×720 picture on the card for the theme creator.
- Free space on the card for the cheat pack and the theme packs.
