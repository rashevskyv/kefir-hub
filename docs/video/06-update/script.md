# 06. Updating Kefir, Kefir Hub and firmware
**Length:** ~6 min · **Docs:** updater.md, settings.md

**Before recording:**
- UI language Ukrainian. Console on the charger the whole session. Wi-Fi connected (the Updater list is downloaded on every open).
- Record the whole video on a **test console, booted into emuMMC**. Firmware install and downgrade write to the system storage of the system you are running; never film them on the main sysMMC.
- An older Kefir installed, so the KEFIR section shows a newer version tagged UPDATE.
- An older firmware on that emuMMC, so the FIRMWARE section shows a newer version, and at least one lower version tagged DOWNGRADE (for the warning box only; the downgrade itself is cancelled with B on camera).
- Saves of the test emuMMC backed up beforehand (the video tells viewers to do this; do it for real too).
- `/firmware` on the memory card holds nothing of yours. Enough free space for a firmware archive plus its unpacked copy.
- For scenes 19-21: a firmware copied to the memory card as a `.zip` archive (for example in `/downloads`).
- For scenes 30-31: an older Kefir Hub build on the card and Settings → General → Auto-update → When to install set to Ask, so the update prompt appears at launch. Set it back to Silent after recording.
- Downgrade fix option left at its default (Automatic). No `/startup.te` in the card root.
