# План впровадження контекстного меню джерел, тестування з'єднання, копіювання URL та відображення всіх джерел у файловому менеджері

Цей план впровадження описує зміни для реалізації таких вимог:
1. Заміна нижнього спливаючого меню (синенького `PopupList`) джерела у налаштуваннях на праве бічне меню (`Sidebar(..., Sidebar::Side::RIGHT)`).
2. Додавання функції тестування мережевого підключення ("Test Connection") як у контекстне меню джерела, так і безпосередньо у меню редагування джерела `SourceEditMenu`.
3. Автоматичне копіювання назви джерела в поле URL, якщо назва схожа на URL-адресу, при його інтерактивному додаванні.
4. Відображення абсолютно всіх мережевих джерел (SMB, FTP, HTTP, WebDAV) у списку вибору джерел ("Mount") файлового менеджера. У разі спроби монтування не-SMB джерел показувати інформаційне повідомлення "Browsing is not supported for this protocol yet.".

## Необхідний розгляд користувачем

> [!IMPORTANT]
> Тестування SMB-підключення вимагатиме наявності активованого макросу `BUILD_SMB2`. Для HTTP, WebDAV та FTP буде використовуватись бібліотека `curl` через вбудований метод `ToMemory`.

### Ручна перевірка
1. Запустити збірку у WSL.
2. Перейти у файловий менеджер, відкрити меню "Sources" (Mount) та переконатися, що у списку джерел відображаються всі створені мережеві локації.
3. Спробувати вибрати джерело WebDAV/FTP/HTTP та переконатися, що з'являється вікно з повідомленням "Browsing is not supported for this protocol yet.".
