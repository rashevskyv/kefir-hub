## 2. Менеджер компонентів (Component Manager) — ⚠️ ЗАМІНЕНО MODULE MANAGER

**Статус:** Стару manifest/components модель прибрано у v0.13.145. Актуальна реалізація описана в розділі 14: `UninstallerMenu` тепер сканує реальні Atmosphere sysmodules за `/atmosphere/contents/*/toolbox.json`, а не читає `/manifest.json`.

**Історичний контекст:** до v0.13.145 цей пункт описував HATS-style component manager із `/manifest.json`, `.disabled` файлами, God Mode та видаленням компонентів. Цей підхід відхилено користувачем і повністю прибрано з коду: `manifest.hpp` / `manifest.cpp` видалені, а залишки слова `manifest` у репозиторії не стосуються Module Manager.

**Актуальна перевірка:** див. розділ 14. Меню має працювати як sysmodules manager: список із `toolbox.json`, A = runtime start/stop для dynamic-модулів, Y = autostart через `boot2.flag`, без видалення та без `/manifest.json`.
